# C-1 在庫棚卸入力

## 基本情報

| 項目       | 内容                    |
| ---------- | ----------------------- |
| 機能ID     | C-1                     |
| 機能名     | 在庫棚卸入力            |
| 画面種別   | 倉庫×商品マトリクス入力 |
| ステータス | DONE                    |
| 備考       |                         |

---

## 機能概要

実地棚卸の結果を入力し、理論在庫との差異を確認・調整する機能。倉庫ごとに棚卸を実施し、実棚数量と理論在庫数量の差異を記録する。差異がある場合は理由を選択し、管理者が確定することで在庫テーブルを実棚数量に更新する。

**主な処理フロー:**

1. 倉庫選択
2. 対象商品の理論在庫を取得・表示
3. 実棚数量を入力
4. 差異自動計算
5. 下書き保存（draft）
6. 管理者が確定（confirmed）
7. 確定時に在庫テーブルを実棚数量に更新

## 画面レイアウト

**上部: ヘッダ情報入力エリア**

- 棚卸日、対象倉庫、棚卸者（自動表示）、ステータス表示

**中部: 商品マトリクステーブル**

- 行: 対象倉庫の在庫商品（全商品）
- 列: 商品コード / 商品名 / 理論在庫数 / 実棚数量（入力） / 差異（自動） / 差異理由（選択） / 備考
- 差異あり商品: 行全体をハイライト表示（黄色背景）

**下部: 操作ボタン**

- 下書き保存、確定（管理者のみ）、キャンセル

## 入力項目

| #   | 項目名     | 型     | 必須 | 初期値             | バリデーション       | 備考             |
| --- | ---------- | ------ | ---- | ------------------ | -------------------- | ---------------- |
| 1   | 棚卸日     | date   | ○    | 当日               | 過去日付のみ許可     | stocktaking_date |
| 2   | 対象倉庫   | select | ○    | -                  | 倉庫マスタから選択   | warehouse_id     |
| 3   | 棚卸者     | string | -    | ログインユーザー名 | 自動設定（変更不可） | stocktaker       |
| 4   | ステータス | string | -    | draft              | draft / confirmed    | status           |

## マトリクス構成

| #   | 列名       | 型     | 入力/自動 | 備考                                          |
| --- | ---------- | ------ | --------- | --------------------------------------------- |
| 1   | 商品コード | string | 自動      | product_code（表示のみ）                      |
| 2   | 商品名     | string | 自動      | product_name（表示のみ）                      |
| 3   | 理論在庫数 | number | 自動      | 在庫テーブルから取得（stock_qty）             |
| 4   | 実棚数量   | number | 入力      | 0以上の整数。必須（確定時）                   |
| 5   | 差異       | number | 自動      | 実棚数量 - 理論在庫数。自動計算               |
| 6   | 差異理由   | select | 入力      | 破損/紛失/数え間違い/その他。差異≠0の場合必須 |
| 7   | 備考       | string | 入力      | 任意。最大500文字                             |

**差異計算式:**

```
差異 = 実棚数量 - 理論在庫数
```

**表示ルール:**

- 差異 > 0: 「+123」形式で緑色表示（過剰）
- 差異 < 0: 「-45」形式で赤色表示（不足）
- 差異 = 0: 「0」で通常表示

## 処理仕様

### 1. 画面初期表示

- 倉庫未選択状態でヘッダのみ表示
- 倉庫選択時に `GET /api/v1/stocks?warehouse_id=xxx` で理論在庫を取得
- 取得した商品リストをマトリクステーブルに表示（実棚数量は空白）

### 2. 下書き保存（全ロール可）

- 入力途中でも保存可能
- ステータス = draft
- `POST /api/v1/stocktakings` で保存
- 実棚数量未入力でもOK（部分入力可）

### 3. 確定処理（管理者のみ: WH_ADMIN, OF_ADMIN, SYS_ADMIN）

- 実棚数量が全商品入力済みであることをチェック
- 差異がある商品は差異理由が必須
- `PUT /api/v1/stocktakings/:id/confirm` で確定
- ステータス = confirmed
- **在庫更新**: 在庫テーブル（stocks）の stock_qty を実棚数量に上書き
- **差異ログ記録**: 差異がある商品は stock_adjustments テーブルに記録
  - adjustment_type: 'stocktaking'
  - quantity_before: 理論在庫数
  - quantity_after: 実棚数量
  - reason: 差異理由
  - notes: 備考

### 4. 編集・削除

- draft状態のみ編集可能（全ロール）
- confirmed状態は編集・削除不可
- 削除は管理者のみ可能

## 在庫差異

**ハイライト表示:**

- 差異がある行（差異 ≠ 0）は行全体を黄色背景で表示
- 差異理由未選択の場合は差異理由セルを赤枠で強調

**差異サマリー表示（マトリクステーブル上部）:**

- 総商品数: 123商品
- 差異あり: 15商品
- 過剰: 8商品（+456個）
- 不足: 7商品（-234個）

**差異ログ（確定後）:**

- stock_adjustments テーブルに記録
- 棚卸履歴として参照可能（将来的に差異分析レポート機能で活用）

## API

| メソッド | エンドポイント                   | 説明                                     |
| -------- | -------------------------------- | ---------------------------------------- |
| GET      | /api/v1/stocktakings             | 棚卸一覧取得（検索・フィルタ対応）       |
| POST     | /api/v1/stocktakings             | 新規棚卸登録（下書き保存）               |
| GET      | /api/v1/stocktakings/:id         | 棚卸詳細取得                             |
| PUT      | /api/v1/stocktakings/:id         | 棚卸更新（draft状態のみ）                |
| PUT      | /api/v1/stocktakings/:id/confirm | 棚卸確定（管理者のみ）                   |
| DELETE   | /api/v1/stocktakings/:id         | 棚卸削除（draft状態かつ管理者のみ）      |
| GET      | /api/v1/stocks?warehouse_id=xxx  | 倉庫別理論在庫取得（棚卸画面初期表示用） |

```json
  "status": "draft",

    {
      "product_id": 10,
      "theoretical_qty": 100,
      "actual_qty": 95,
      "difference": -5,
      "difference_reason": "紛失",

      "difference": 2,
```

```json
}
```

## 権限

| ロール    | 許可される操作                                                                     |
| --------- | ---------------------------------------------------------------------------------- |
| WH_USER   | 閲覧（R）、新規登録（C）、編集（U: draft状態のみ）                                 |
| WH_ADMIN  | 閲覧（R）、新規登録（C）、編集（U: draft状態のみ）、確定、削除（D: draft状態のみ） |
| OF_USER   | 閲覧（R）、新規登録（C）、編集（U: draft状態のみ）                                 |
| OF_ADMIN  | 閲覧（R）、新規登録（C）、編集（U: draft状態のみ）、確定、削除（D: draft状態のみ） |
| SYS_ADMIN | すべての操作（CRUD + 確定）                                                        |

**確定権限（confirm）:**

- WH_ADMIN, OF_ADMIN, SYS_ADMIN のみ可能
- 確定後は編集・削除不可

## エラーハンドリング

| エラー条件                         | メッセージ                                     | 挙動                            |
| ---------------------------------- | ---------------------------------------------- | ------------------------------- |
| 必須項目未入力（棚卸日、倉庫）     | 「棚卸日と対象倉庫は必須です」                 | 保存不可。入力欄を赤枠表示      |
| 実棚数量が負の値                   | 「実棚数量は0以上の整数を入力してください」    | 保存不可。該当セルを赤枠表示    |
| 差異あり＋差異理由未選択（確定時） | 「差異がある商品は差異理由を選択してください」 | 確定不可。該当行をハイライト    |
| 実棚数量未入力（確定時）           | 「全商品の実棚数量を入力してください」         | 確定不可。未入力セルを赤枠表示  |
| confirmed状態の編集試行            | 「確定済みの棚卸は編集できません」             | 403エラー。編集ボタンを非活性化 |
| 一般ユーザーの確定試行             | 「棚卸確定は管理者のみ実行できます」           | 403エラー。確定ボタンを非表示   |
| 一般ユーザーの削除試行             | 「棚卸削除は管理者のみ実行できます」           | 403エラー。削除ボタンを非表示   |
| 倉庫IDが存在しない                 | 「指定された倉庫が見つかりません」             | 404エラー。倉庫選択をやり直し   |
| サーバーエラー                     | 「棚卸処理中にエラーが発生しました」           | 500エラー。エラー通知を表示     |
