---

## 機能概要

倉庫ごとの現在の在庫状況を一覧表示する機能。各倉庫に保管されている商品の在庫数量を確認し、在庫切れや過剰在庫を把握できる。倉庫や商品カテゴリでフィルタリング可能で、CSV出力や棚卸画面への遷移もサポートする。

**主な用途:**

- 倉庫別の在庫状況確認
- 在庫切れ商品の検出
- 棚卸準備（理論在庫の事前確認）
- 在庫レポート出力（CSV）

## 画面レイアウト

**上部: フィルタエリア**

- 倉庫選択（プルダウン）、商品カテゴリ選択、在庫あり/なし切替、キーワード検索（商品コード/商品名）、検索ボタン

**中部: 一覧テーブル**

- ヘッダ: 倉庫名 / 商品コード / 商品名 / カテゴリ / 現在庫数 / 単位 / 最終更新日時
- ソート機能: 商品コード、商品名、現在庫数、最終更新日時でソート可能
- 行クリック: 商品詳細画面へ遷移（将来対応）

**下部: 操作エリア**

- ページネーション（前へ / 次へ / ページ番号）
- 表示件数選択（20 / 50 / 100件）
- CSV出力ボタン
- 棚卸画面へ遷移ボタン（選択中の倉庫で棚卸開始）

**在庫状態の視覚化:**

- 在庫数 = 0: 赤色太字表示 + 「在庫切れ」ラベル
- 在庫数 > 0 かつ < 10: 黄色背景 + 「残少」ラベル
- 在庫数 >= 10: 通常表示

## 一覧表示項目

| #   | 項目名       | 型       | ソート | 備考                                                |
| --- | ------------ | -------- | ------ | --------------------------------------------------- |
| 1   | 倉庫名       | string   | -      | warehouse.name（フィルタで選択された倉庫名）        |
| 2   | 商品コード   | string   | ○      | product.code（昇順/降順）                           |
| 3   | 商品名       | string   | ○      | product.name（昇順/降順）                           |
| 4   | カテゴリ     | string   | -      | product.category                                    |
| 5   | 現在庫数     | number   | ○      | stock.quantity（昇順/降順）。0の場合は赤色表示      |
| 6   | 単位         | string   | -      | product.unit（例: 個、箱、kg）                      |
| 7   | 最終更新日時 | datetime | ○      | stock.updated_at（昇順/降順）。YYYY-MM-DD HH:mm形式 |

**デフォルトソート:**

- 商品コード昇順

## フィルタ条件

| #   | 項目名       | 型     | 検索方式 | 初期値 | 備考                                           |
| --- | ------------ | ------ | -------- | ------ | ---------------------------------------------- |
| 1   | 倉庫         | select | 完全一致 | すべて | 倉庫マスタから選択。「すべて」選択で全倉庫表示 |
| 2   | 商品カテゴリ | select | 完全一致 | すべて | 商品マスタのカテゴリから選択                   |
| 3   | 在庫状態     | select | 条件分岐 | すべて | すべて / 在庫あり（>0） / 在庫切れ（=0）       |
| 4   | キーワード   | text   | 部分一致 | -      | 商品コードまたは商品名に対してLIKE検索         |

**フィルタ適用タイミング:**

- 検索ボタンクリック時
- 倉庫選択変更時（即時反映）
- Enter キー押下時（キーワード検索）

## ページネーション

| 項目               | 値                                                   |
| ------------------ | ---------------------------------------------------- |
| デフォルト表示件数 | 50件                                                 |
| 選択可能件数       | 20件 / 50件 / 100件                                  |
| ページ番号表示     | 現在ページ ± 2ページを表示（例: 1 2 [3] 4 5 ... 10） |

**ページネーション仕様:**

- 総件数表示: 「全 123 件中 51-100 件を表示」
- 前へ/次へボタン: 先頭ページ/最終ページでは非活性化
- ページ番号直接選択可能

## 操作機能

### 1. CSV出力

- 現在のフィルタ条件に一致する全データを出力（ページネーション無視）
- ファイル名: `warehouse_stock_YYYYMMDD_HHmmss.csv`
- 出力項目: 倉庫名, 商品コード, 商品名, カテゴリ, 現在庫数, 単位, 最終更新日時
- 最大出力件数: 10,000件（超過時は警告表示）

### 2. 棚卸画面へ遷移

- 選択中の倉庫で棚卸入力画面（C-1）を開く
- 倉庫未選択時はボタン非活性化
- 遷移時に倉庫IDをクエリパラメータで渡す: `/stocktaking?warehouse_id=1`

## API

| メソッド | エンドポイント        | 説明                                                 |
| -------- | --------------------- | ---------------------------------------------------- |
| GET      | /api/v1/stocks        | 倉庫別在庫一覧取得（フィルタ・ページネーション対応） |
| GET      | /api/v1/stocks/export | CSV出力用データ取得（全件）                          |

**リクエスト例（一覧取得）:**

```
GET /api/v1/stocks?warehouse_id=1&category=食品&status=available&keyword=りんご&page=1&limit=50&sort=code&order=asc
```

**クエリパラメータ:**

- `warehouse_id`: 倉庫ID（オプション。未指定で全倉庫）
- `category`: 商品カテゴリ（オプション）
- `status`: 在庫状態（available: >0, out_of_stock: =0）（オプション）
- `keyword`: 商品コード/商品名の部分一致検索（オプション）
- `page`: ページ番号（デフォルト: 1）
- `limit`: 表示件数（デフォルト: 50）
- `sort`: ソート項目（code, name, quantity, updated_at）（デフォルト: code）
- `order`: ソート順（asc, desc）（デフォルト: asc）

## 権限

| ロール    | 許可される操作     |
| --------- | ------------------ |
| WH_USER   | 閲覧（R）、CSV出力 |
| WH_ADMIN  | 閲覧（R）、CSV出力 |
| OF_USER   | 閲覧（R）、CSV出力 |
| OF_ADMIN  | 閲覧（R）、CSV出力 |
| SYS_ADMIN | 閲覧（R）、CSV出力 |

**注記:**

- 全ロールが閲覧のみ可能（参照専用画面）
- 在庫数の直接編集は不可（入荷・出荷・棚卸経由でのみ更新）

## エラーハンドリング

| エラー条件         | メッセージ                                                                         | 挙動                             |
| ------------------ | ---------------------------------------------------------------------------------- | -------------------------------- |
| 倉庫IDが存在しない | 「指定された倉庫が見つかりません」                                                 | 404エラー。フィルタをリセット    |
| ページ番号が範囲外 | 「指定されたページが見つかりません」                                               | 400エラー。1ページ目を表示       |
| CSV出力件数超過    | 「出力可能な最大件数（10,000件）を超えています。フィルタ条件を絞り込んでください」 | 400エラー。エラーダイアログ表示  |
| サーバーエラー     | 「在庫データの取得中にエラーが発生しました」                                       | 500エラー。エラー通知を表示      |
| ネットワークエラー | 「通信エラーが発生しました。再読み込みしてください」                               | 接続エラー。再読み込みボタン表示 |

## UI/UX 考慮事項

**レスポンシブ対応:**

- モバイル表示時はテーブルをカード形式に切替
- フィルタエリアは折りたたみ可能

**ローディング状態:**

- 初回読み込み時: スケルトンローダー表示
- ページ遷移時: スピナー表示
- CSV出力時: ダウンロード中インジケーター

**アクセシビリティ:**

- ソート可能な列ヘッダにはaria-sort属性を付与
- 在庫切れ商品には `aria-label="在庫切れ"` を付与
