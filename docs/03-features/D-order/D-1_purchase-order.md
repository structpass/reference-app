# D-1 発注入力

## 基本情報

| 項目       | 内容                       |

| 機能ID     | D-1                        |
| 機能名     | 発注入力                   |
| 画面種別   | 伝票入力（ヘッダ＋明細行） |
| ステータス | DONE                       |

## 機能概要

仕入先への発注データを入力・管理する機能。発注番号、発注日、仕入先、希望納期などのヘッダ情報と、商品・数量・単価などの明細行情報を入力し、発注伝票を作成する。下書き保存後に発注確定を行い、入荷時に入荷入力画面（B-1）で紐付けることで入荷実績を記録する。

**主な処理フロー:**

1. ヘッダ情報入力（発注日、仕入先、希望納期）
2. 明細行追加（商品選択、発注数量、単価入力）
3. 下書き保存（draft）
4. 発注確定（ordered）
5. 入荷連携（B-1入荷入力で入荷時に紐付け）
6. 完了（completed）

**ステータス遷移:**

- draft（下書き）→ ordered（発注済み）→ partially_received（一部入荷）→ completed（完了）

## 画面レイアウト

**上部: ヘッダ情報入力エリア**

- 発注番号（自動採番、表示のみ）、発注日、仕入先（検索・選択）、希望納期、ステータス表示、備考

**中部: 明細行テーブル**

- ヘッダ: 行番号 / 商品 / 発注数量 / 単価 / 金額 / 単位 / 備考 / 操作（削除）
- 行追加ボタン: テーブル下部に配置
- 合計行: 総数量、総金額を自動計算

**下部: 操作ボタン**

- 下書き保存、発注確定（全ロール可）、削除（管理者のみ）、キャンセル

**自動計算:**

- 金額 = 発注数量 × 単価（明細行ごと）
- 総数量 = 全明細行の発注数量合計
- 総金額 = 全明細行の金額合計

| --- | ---------- | ------ | ---- | ---------- | ------------------------------------------------ | ----------------------------------------- |

| 2   | 発注日     | date   | ○    | 当日       | 過去日付のみ許可                                 | order_date                                |
| 3   | 仕入先     | string | ○    | -          | 仕入先マスタから検索・選択                       | supplier（テキスト入力 + サジェスト）     |
| 4   | 希望納期   | date   | ○    | 発注日+7日 | 発注日以降の日付のみ許可                         | desired_delivery_date                     |
| 5   | ステータス | string | -    | draft      | draft / ordered / partially_received / completed | status（自動設定）                        |

**発注番号の採番ルール:**

- フォーマット: `PO-YYYYMMDD-XXX`
- 例: `PO-20260315-001`
- XXX: 当日の連番（001から開始）

## 明細行項目

| #   | 項目名   | 型     | 必須 | 初期値             | バリデーション               | 備考                                        |
| --- | -------- | ------ | ---- | ------------------ | ---------------------------- | ------------------------------------------- |
| 1   | 行番号   | number | -    | 自動               | -                            | line_no（1から自動採番）                    |
| 2   | 商品     | select | ○    | -                  | 商品マスタから検索・選択     | product_id（商品コード/商品名で検索）       |
| 3   | 発注数量 | number | ○    | -                  | 1以上の整数                  | order_qty                                   |
| 4   | 単価     | number | ○    | 商品マスタから自動 | 0以上の数値（小数点2桁まで） | unit_price（手動変更可）                    |
| 5   | 金額     | number | -    | 自動計算           | -                            | amount = order_qty × unit_price（自動計算） |
| 6   | 単位     | string | -    | 商品マスタから自動 | -                            | unit（例: 個、箱、kg）。表示のみ            |
| 7   | 備考     | text   | -    | -                  | 最大500文字                  | notes                                       |

**商品選択UI:**

- テキスト入力 + ドロップダウンサジェスト
- 商品コードまたは商品名で部分一致検索
- 選択時に単価と単位を自動入力（商品マスタの仕入単価を取得）

**行追加/削除:**

- 行追加ボタン: テーブル下部に「+ 明細行を追加」ボタン
- 行削除ボタン: 各行の右端に削除アイコン（ゴミ箱）
- 最低1行は必須（全削除不可）

## 処理仕様

### 1. 新規作成

- 画面初期表示時はヘッダのみ表示（明細行は1行空白）
- 発注番号は保存時に自動採番
- 発注日は当日、希望納期は発注日+7日をデフォルト設定

### 2. 下書き保存（全ロール可）

- 入力途中でも保存可能
- ステータス = draft
- `POST /api/v1/orders` で保存
- 明細行が1行以上必須（空白行は除外）
- 発注数量0以下の行は保存不可

### 3. 発注確定（全ロール可）

- ヘッダ必須項目（発注日、仕入先、希望納期）がすべて入力済みであることをチェック
- 明細行が1行以上あることをチェック
- 各明細行の必須項目（商品、発注数量、単価）がすべて入力済みであることをチェック
- `PUT /api/v1/orders/:id/confirm` で確定
- ステータス = ordered
- 確定後は編集可能（ただし発注番号は変更不可）

### 4. 入荷連携

- 入荷入力画面（B-1）で入荷時に発注IDを紐付け
- 入荷数量が発注数量に達したらステータス = completed
- 一部入荷の場合はステータス = partially_received

### 5. 編集（全ロール可）

- draft, ordered, partially_received 状態のみ編集可能
- completed 状態は編集不可（閲覧のみ）
- `PUT /api/v1/orders/:id` で更新

### 6. 削除（管理者のみ: WH_ADMIN, OF_ADMIN, SYS_ADMIN）

- draft 状態のみ削除可能
- ordered, partially_received, completed 状態は削除不可
- `DELETE /api/v1/orders/:id` で削除

## API

| メソッド | エンドポイント             | 説明                                                |
| -------- | -------------------------- | --------------------------------------------------- |
| GET      | /api/v1/orders             | 発注一覧取得（検索・フィルタ対応）                  |

## 権限

| ロール    | 許可される操作                                                                               |
| --------- | -------------------------------------------------------------------------------------------- |
| WH_USER   | 閲覧（R）、新規登録（C）、編集（U: draft/ordered/partially_received）                        |
| WH_ADMIN  | 閲覧（R）、新規登録（C）、編集（U: draft/ordered/partially_received）、削除（D: draft のみ） |
| OF_USER   | 閲覧（R）、新規登録（C）、編集（U: draft/ordered/partially_received）                        |
| OF_ADMIN  | 閲覧（R）、新規登録（C）、編集（U: draft/ordered/partially_received）、削除（D: draft のみ） |
| SYS_ADMIN | すべての操作（CRUD + 確定）                                                                  |

**削除権限:**

- WH_ADMIN, OF_ADMIN, SYS_ADMIN のみ可能
- draft 状態のみ削除可能

**編集制限:**

- completed 状態は編集不可（全ロール）
- 発注番号は常に変更不可

## エラーハンドリング

| エラー条件                                     | メッセージ                                       | 挙動                              |
| ---------------------------------------------- | ------------------------------------------------ | --------------------------------- |
| 必須項目未入力（発注日、仕入先、希望納期）     | 「発注日、仕入先、希望納期は必須です」           | 保存不可。入力欄を赤枠表示        |
| 希望納期が発注日より前                         | 「希望納期は発注日以降の日付を指定してください」 | 保存不可。希望納期欄を赤枠表示    |
| 明細行が0行                                    | 「明細行を1行以上追加してください」              | 保存不可。エラー通知を表示        |
| 発注数量が0以下                                | 「発注数量は1以上の整数を入力してください」      | 保存不可。該当セルを赤枠表示      |
| 単価が負の値                                   | 「単価は0以上の数値を入力してください」          | 保存不可。該当セルを赤枠表示      |
| 明細行の必須項目未入力（商品、発注数量、単価） | 「商品、発注数量、単価は必須です」               | 確定不可。該当セルを赤枠表示      |
| completed状態の編集試行                        | 「完了済みの発注は編集できません」               | 403エラー。編集ボタンを非活性化   |
| 一般ユーザーの削除試行                         | 「発注削除は管理者のみ実行できます」             | 403エラー。削除ボタンを非表示     |
| draft以外の削除試行                            | 「発注済みまたは入荷済みの発注は削除できません」 | 409エラー。削除不可メッセージ表示 |
| 存在しない発注IDの取得                         | 「指定された発注が見つかりません」               | 404エラー。一覧画面へリダイレクト |
| サーバーエラー                                 | 「発注処理中にエラーが発生しました」             | 500エラー。エラー通知を表示       |

## UI/UX 考慮事項

**ステータス表示:**

- draft: グレーバッジ「下書き」
- ordered: 青バッジ「発注済み」
- partially_received: 黄バッジ「一部入荷」
- completed: 緑バッジ「完了」

**自動計算の挙動:**

- 発注数量または単価の変更時に金額を即座に再計算
- 明細行追加/削除時に総数量・総金額を即座に再計算

**商品選択UI:**

- テキスト入力時にリアルタイムでサジェスト表示（最大10件）
- 商品コード（P-001）と商品名（りんご）を併記
- Enter キーで先頭候補を選択

**レスポンシブ対応:**

- モバイル表示時は明細行をカード形式に切替
- 合計行は固定表示（スクロール時も表示）

**アクセシビリティ:**

- 行削除ボタンに `aria-label="明細行を削除"` を付与
- 必須項目に `required` 属性を付与

## バリデーションルール詳細

**発注数量:**

- 1以上の整数のみ許可
- 小数点入力不可
- 最大値: 999,999

**単価:**

- 0以上の数値
- 小数点2桁まで許可
- 最大値: 9,999,999.99

**備考:**

- ヘッダ備考: 最大1000文字
- 明細行備考: 最大500文字

**仕入先:**

- 既存仕入先から選択（新規仕入先は仕入先マスタで事前登録が必要）
