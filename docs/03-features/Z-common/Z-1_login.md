## 機能概要

ユーザーIDとパスワードによる認証を行い、JWTトークンを取得する画面。認証成功時はダッシュボード（メニュー画面）へ遷移する。認証失敗時にはエラーメッセージを表示し、連続失敗（5回）でアカウントロックを行う。

## 画面レイアウト

- 中央配置のログインフォーム
  - StructPassロゴ（上部）
  - ユーザーID入力フィールド
  - パスワード入力フィールド（マスク表示、表示/非表示切替ボタン付き）
  - ログインボタン（プライマリ色、全幅）
  - エラーメッセージ表示エリア（入力フォーム下部、エラー時のみ表示）
- 背景: グラデーション or 単色
- レスポンシブ対応: モバイル時は画面幅の90%、デスクトップ時は固定幅（400px）

## 入力項目

| #   | 項目名     | 型       | 必須 | 初期値 | バリデーション          | 備考                                                      |
| --- | ---------- | -------- | ---- | ------ | ----------------------- | --------------------------------------------------------- |
| 1   | ユーザーID | text     | ○    | なし   | 半角英数字、4-50文字    | プレースホルダー: "User ID"                               |
| 2   | パスワード | password | ○    | なし   | 半角英数記号、8-100文字 | プレースホルダー: "Password"、表示/非表示切替アイコン付き |

## 処理仕様

### ログイン処理フロー

1. **入力バリデーション**
   - ユーザーIDとパスワードの形式チェック（クライアント側）
   - 空欄チェック、文字数チェック、文字種チェック
   - エラー時は該当フィールドを赤枠表示し、フィールド下部にエラーメッセージ表示

2. **認証API呼び出し**
   - `POST /api/v1/auth/login` を実行
   - リクエストボディ: `{ username: string, password: string }`
   - レスポンス成功時: `{ success: true, data: { accessToken: string, refreshToken: string, user: {...} } }`

3. **トークン保存**
   - `accessToken`と`refreshToken`をlocalStorageに保存
   - ユーザー情報（id, username, role）もlocalStorageに保存

4. **画面遷移**
   - `/dashboard` へリダイレクト（router.replace使用）

5. **エラー時の挙動**
   - 認証失敗（401）: "ユーザーIDまたはパスワードが正しくありません"を表示
   - アカウントロック（423）: "アカウントがロックされています。管理者にお問い合わせください"を表示
   - サーバーエラー（500）: "サーバーエラーが発生しました。しばらくしてから再度お試しください"を表示
   - ネットワークエラー: "ネットワークエラーが発生しました。接続を確認してください"を表示

### セキュリティ仕様

- パスワードは平文で送信しない（HTTPS必須）
- ログイン試行回数制限: 同一ユーザーIDで5回連続失敗した場合、30分間アカウントロック
- ロック解除: 管理者による手動解除、または30分経過後の自動解除
- CSRF保護: トークンベース認証のため不要（Cookie未使用）

## API

| メソッド | エンドポイント       | 説明                                                                              |
| -------- | -------------------- | --------------------------------------------------------------------------------- |
| POST     | /api/v1/auth/login   | ユーザー認証を行い、JWTトークンを返す。リクエストボディ: `{ username, password }` |
| POST     | /api/v1/auth/refresh | アクセストークンの更新。リクエストボディ: `{ refreshToken }`                      |

## 権限

| ロール    | 許可される操作                                                           |
| --------- | ------------------------------------------------------------------------ |
| 全ロール  | ログイン可能（認証前のため、ロール制御なし）                             |
| WH_USER   | ログイン成功後、倉庫担当一般権限でダッシュボードへ                       |
| WH_ADMIN  | ログイン成功後、倉庫担当管理者権限でダッシュボードへ                     |
| OF_USER   | ログイン成功後、事務担当一般権限でダッシュボードへ                       |
| OF_ADMIN  | ログイン成功後、事務担当管理者権限でダッシュボードへ                     |
| SYS_ADMIN | ログイン成功後、システム管理者権限でダッシュボードへ（全機能アクセス可） |
