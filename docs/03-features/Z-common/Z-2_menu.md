## 機能概要

ログイン後に表示されるメインナビゲーション。サイドバー形式で全機能へのリンクを提供する。ユーザーのロールと権限設定（A-10機能別権限設定）に基づき、アクセス権のない機能は非表示にする。ダッシュボード本体はメインコンテンツ領域に表示され、各種統計情報や直近の操作履歴を表示する。

## 画面レイアウト

### 全体構成

- **左サイドバー**（幅: 240px、折りたたみ可能）
  - StructPassロゴ（上部）
  - カテゴリ別メニュー（アコーディオン形式）
    - Z. 共通
    - A. マスタ管理
    - B. 入出荷管理
    - C. 在庫管理
    - D. 発注管理
  - ユーザー情報表示（下部固定）
    - ユーザー名、ロール名表示
    - ログアウトボタン

- **右メインコンテンツ領域**（残り幅100%）
  - ページヘッダー（パンくずリスト、ページタイトル）
  - コンテンツ本体（各機能の画面が表示される）
  - ダッシュボード時の表示内容:
    - 統計カード（商品総数、倉庫数、今日の入荷/出荷件数）
    - 直近の操作履歴（最新10件）
    - 在庫アラート（在庫数が閾値以下の商品一覧）

- **トップバー**（オプション、モバイル時は必須）
  - メニュー開閉ボタン（ハンバーガーアイコン）
  - ページタイトル
  - ユーザーアイコン＋ドロップダウン（ログアウト）

### レスポンシブ対応

- デスクトップ（1024px以上）: サイドバー常時表示
- タブレット（768-1023px）: サイドバー折りたたみ可能、デフォルト展開
- モバイル（767px以下）: サイドバーをオーバーレイ表示（デフォルト非表示）、トップバーのハンバーガーメニューで開閉

## 処理仕様

### メニュー表示制御フロー

1. **ページロード時の初期化**
   - localStorageからJWTトークンを取得
   - トークンが存在しない場合、ログイン画面（/login）へリダイレクト
   - トークンの有効期限チェック（期限切れの場合、refreshTokenで更新試行）

2. **ユーザー情報取得**
   - JWTトークンからユーザー情報（id, username, role）をデコード
   - または `GET /api/v1/auth/me` でユーザー情報を再取得
   - ロール情報をステートに保存

3. **メニューフィルタリング**
   - **ステップ1: ロールベースフィルタ**
     - WH_USER/OF_USER: 登録系（new）画面を非表示、一覧・入力系のみ表示
     - WH_ADMIN/OF_ADMIN: ユーザー・グループ・権限設定以外を表示
     - SYS_ADMIN: 全メニュー表示

   - **ステップ2: カスタム権限適用**（A-10機能別権限設定）
     - `GET /api/v1/permissions/my-permissions` でユーザー/グループ別のカスタム権限を取得
     - 個別機能の参照可否（isViewable）がfalseの場合、該当メニューを非表示
     - ロールベースの権限よりもカスタム権限を優先

4. **メニュー描画**
   - フィルタリング後のメニュー項目をカテゴリ別にグループ化
   - アコーディオン形式で各カテゴリを展開/折りたたみ可能に
   - アクティブページのメニュー項目をハイライト表示（背景色変更）

5. **ログアウト処理**
   - ログアウトボタン押下時
   - localStorageからトークンとユーザー情報を削除
   - （オプション）`POST /api/v1/auth/logout` でサーバー側のトークン無効化
   - `/login` へリダイレクト（router.replace使用）

### トークン自動更新

- アクセストークンの有効期限: 15分
- リフレッシュトークンの有効期限: 7日
- APIリクエスト時に401エラーが返った場合、自動的にrefreshTokenでトークン更新を試行
- 更新成功時: 新しいaccessTokenでリクエストを再実行
- 更新失敗時: ログイン画面へリダイレクト

## 権限

| ロール    | 表示されるメニュー                                                                                                |
| --------- | ----------------------------------------------------------------------------------------------------------------- |
| WH_USER   | Z（全て）、A（一覧・検索のみ）、B（入荷入力、入出荷一覧）、C（棚卸入力、倉庫別在庫一覧、予測在庫一覧）、D（なし） |
| WH_ADMIN  | Z（全て）、A（ユーザー・グループ・権限設定以外の全て）、B（全て）、C（全て）、D（なし）                           |
| OF_USER   | Z（全て）、A（一覧・検索のみ）、B（出荷入力、入出荷一覧）、C（倉庫別在庫一覧、予測在庫一覧）、D（発注入力）       |
| OF_ADMIN  | Z（全て）、A（ユーザー・グループ・権限設定以外の全て）、B（全て）、C（全て）、D（全て）                           |
| SYS_ADMIN | 全メニュー（Z,A,B,C,D の全機能）                                                                                  |

### 権限詳細

- **登録系画面（new）**: ADMIN系ロール以上
- **一覧・検索画面**: 全ロール
- **詳細画面**: 全ロール（一覧から遷移）
- **ユーザー・グループ管理**: ADMIN系ロール以上（一覧のみ）、SYS_ADMIN（登録・編集・削除）
- **権限設定（A-10）**: SYS_ADMINのみ

### ロール別権限設定（A-10機能別権限設定）

- ロール単位で各機能の参照可否を個別設定できる（設定単位はロール。ユーザー単位・グループ単位の設定は未実装）
- 設定した値はロールの既定権限を置き換え、対象ロールの利用者が次にアクセスした時から適用される
- 例: WH_ADMIN でも、権限設定で B-3 入出荷一覧を非表示にできる
