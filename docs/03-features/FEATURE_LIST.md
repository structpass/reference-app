# StructPass 機能一覧

## 概要

StructPass（商品管理システム）の全機能を定義・管理するドキュメント。
全 30 機能（6 カテゴリ）で構成し、Phase 1〜6 で実装済 + 運用機能（システム設定 / ファイル取込）を 2026-04 以降に追加。
掲示板（E-1 / E-2）は撤去して rete の Home 掲示板へ集約し、監査ログ（E-4）は記録だけを提供する。

## ステータス凡例

| ステータス  | 意味                                                   |
| ----------- | ------------------------------------------------------ |
| DONE        | 実装済み                                               |
| TODO        | 未着手                                                 |
| IN_PROGRESS | 開発中                                                 |
| 移管        | 本リポジトリでは画面を提供しない（他プロダクトへ集約） |
| 記録のみ    | 記録側だけ実装済み。閲覧の画面・参照 API は提供しない  |

## 基盤（機能数に不算入）

固定の画面番号を持たない基盤。OT-1 は台帳ごとに画面を動的生成するため、上記の機能カウント（全 30 機能 / 6 カテゴリ）には含めない。

| #    | 名称                         | 種別                        | ステータス | 備考                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ---- | ---------------------------- | --------------------------- | ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| OT-1 | カスタムオブジェクト定義基盤 | backend API + frontend 画面 | DONE       | object-types モジュール（種別 / フィールド定義 / 汎用レコード）。台帳管理画面（`/dashboard/object-types`）と自由定義レコード画面（`/dashboard/custom/<key>`）を提供し、台帳管理はサイドバー「システム管理」、プリセット・ユーザー定義の台帳は「マスタ管理」へ並ぶ。権限は、台帳定義の作成・更新が固定 `object-types`、種別の取得と自由定義レコード操作がプリセットは `object-types`・ユーザー定義は `object-type:<key>`。台帳定義の削除 API はない。 |

## 設計方針

- **マスタ管理**: 各マスタは「一覧」「詳細入力」「検索」の 3 画面セットで構成
- **入出荷管理**: 伝票単位（ヘッダ＋明細行）で入力。入荷と出荷は統合一覧で確認
- **在庫管理**: 倉庫×商品の組み合わせで在庫を管理。棚卸・現在庫・予測在庫の 3 画面
- **発注管理**: 伝票単位（ヘッダ＋明細行）で発注を入力
- **運用機能**: システム設定（公開・非公開キー）、監査ログの自動記録、CSV ファイル取込でバックオフィス運用を支援。掲示板は rete の Home 掲示板へ集約
