## 機能概要

入荷伝票と出荷伝票を統合して一覧表示する機能。種別（入荷/出荷）、期間、倉庫、ステータスでフィルタリングでき、各伝票の概要を把握できる。詳細表示やCSV出力により、業務の進捗確認や報告資料作成を支援する。

**主な用途:**

- 入出荷業務の進捗確認
- 期間別・倉庫別の入出荷実績集計
- 伝票の検索・詳細確認
- CSV出力による外部システム連携・報告

## 一覧表示項目

| #   | 項目名     | 型       | ソート | 備考                                  |
| --- | ---------- | -------- | ------ | ------------------------------------- |
| 1   | 種別       | string   | ○      | 「入荷」または「出荷」、色分け表示    |
| 2   | 伝票番号   | string   | ○      | RCV-YYYYMMDD-XXXX / SHP-YYYYMMDD-XXXX |
| 3   | 日付       | Date     | ○      | 入荷日 / 出荷日、MM/DD形式            |
| 4   | 倉庫名     | string   | ○      | 倉庫マスタの名称                      |
| 5   | 相手先     | string   | ○      | 入荷の場合:仕入先、出荷の場合:届先    |
| 6   | ステータス | enum     | ○      | 下書き/確定/完了(入荷) or 出荷(出荷)  |
| 7   | 明細行数   | number   | -      | 伝票に含まれる明細行の総数            |
| 8   | 登録者     | string   | ○      | 伝票を作成したユーザー名              |
| 9   | 登録日時   | DateTime | ○      | YYYY-MM-DD HH:mm 形式                 |
| 10  | 操作       | -        | -      | [詳細]ボタン                          |

**表示の工夫:**

- 種別: 入荷は青アイコン、出荷は緑アイコンで視覚的に区別
- ステータス: バッジ表示（下書き:グレー、確定:青、完了:緑）
- 日付: デフォルトで降順ソート（最新の伝票が上位）
- 相手先: 長い場合は省略表示（ホバーで全文表示）

## フィルタ条件

| #   | 項目名       | 型     | 検索方式 | 初期値   | 備考                                        |
| --- | ------------ | ------ | -------- | -------- | ------------------------------------------- |
| 1   | 種別         | select | 完全一致 | すべて   | すべて/入荷/出荷                            |
| 2   | 期間（開始） | Date   | 範囲検索 | 当月1日  | date picker、日付以降の伝票を表示           |
| 3   | 期間（終了） | Date   | 範囲検索 | 当月末日 | date picker、日付以前の伝票を表示           |
| 4   | 倉庫         | select | 完全一致 | すべて   | 倉庫マスタから取得、warehouse_id で絞り込み |
| 5   | ステータス   | select | 完全一致 | すべて   | すべて/下書き/確定/完了/出荷                |
| 6   | 伝票番号     | text   | 部分一致 | -        | 任意入力、RCVまたはSHPで始まる番号          |
| 7   | 相手先       | text   | 部分一致 | -        | 任意入力、仕入先または届先で検索            |

**フィルタ操作:**

- [検索]ボタン: フィルタ条件を適用して再検索
- [クリア]ボタン: 全フィルタを初期値にリセット
- フィルタ変更時は1ページ目に戻る
- URLクエリパラメータでフィルタ状態を保持（ブックマーク・共有可能）

## ページネーション

| 項目               | 値                                   |
| ------------------ | ------------------------------------ |
| デフォルト表示件数 | 20件                                 |
| 選択可能件数       | 10件 / 20件 / 50件 / 100件           |
| ページ送り         | [◀ 前へ] [次へ ▶] + ページ番号リンク |
| 総件数表示         | 「全XXX件中 YY-ZZ件を表示」          |

**ページネーション仕様:**

- ページ番号: 最大5ページ分を表示（例: 1 2 3 4 5）
- 6ページ以上ある場合: 1 2 3 ... 10 のように省略表示
- 現在ページ: 太字＋下線で強調
- 件数変更時: 1ページ目に戻る
- URLクエリパラメータでページ状態を保持（例: ?page=2&limit=20）

## 操作ボタン

| ボタン名        | 動作                | 権限     | 備考                                 |
| --------------- | ------------------- | -------- | ------------------------------------ |
| 詳細            | 伝票詳細画面へ遷移  | 全ロール | 入荷はB-1、出荷はB-2の編集画面を開く |
| CSVエクスポート | 一覧データをCSV出力 | 全ロール | 現在のフィルタ条件で全件出力         |
| 検索            | フィルタ条件を適用  | 全ロール | フィルタエリア内                     |
| クリア          | フィルタをリセット  | 全ロール | フィルタエリア内                     |

**CSV出力仕様:**

- ファイル名: `shipping_list_YYYYMMDD_HHmmss.csv`
- 文字コード: UTF-8 with BOM（Excel対応）
- 区切り文字: カンマ（,）
- ヘッダー行: あり
- 出力項目: 種別、伝票番号、日付、倉庫名、相手先、ステータス、明細行数、登録者、登録日時
- 出力対象: 現在のフィルタ条件に一致する全件（ページネーション無視）
- 最大出力件数: 10,000件（超える場合は警告表示）

**CSV出力例:**

```csv
種別,伝票番号,日付,倉庫名,相手先,ステータス,明細行数,登録者,登録日時
入荷,RCV-20260316-001,2026-03-16,東京倉庫,ABC商事株式会社,確定,2,admin,2026-03-16 10:30:00
出荷,SHP-20260316-001,2026-03-16,東京倉庫,株式会社XYZ,下書き,3,user,2026-03-16 11:00:00
```

## API

| メソッド | エンドポイント          | 説明                      |
| -------- | ----------------------- | ------------------------- |
| GET      | /api/v1/shipping        | 入出荷一覧取得（統合API） |

| GET      | /api/v1/shipping/export | 入出荷一覧CSV出力         |

**リクエスト例（統合API）:**

```
GET /api/v1/shipping?type=all&start_date=2026-03-01&end_date=2026-03-31&warehouse_id=1&status=confirmed&page=1&limit=20&sort=date&order=desc
```

**クエリパラメータ:**
| パラメータ | 型 | 必須 | 説明 |
|-----------|---|------|------|
| type | string | - | all/receiving/shipment、デフォルト: all |

| page | number | - | ページ番号、デフォルト: 1 |
| limit | number | - | 表示件数、デフォルト: 20 |
| sort | string | - | ソート項目、デフォルト: date |

**権限制御の詳細:**

- 全ロール: 閲覧のみ（作成・更新・削除は各伝票画面で実施）

- CSV出力: 全ロールが実行可能（機密情報は含まれない前提）

## エラーハンドリング

| エラー条件         | メッセージ                                                                       | 挙動                                            |
| ------------------ | -------------------------------------------------------------------------------- | ----------------------------------------------- |
| 無効な期間指定     | 「期間の指定が不正です（開始日 > 終了日）」                                      | 400 Bad Request、フィルタエリアにエラー表示     |
| 無効な倉庫ID       | 「指定された倉庫が見つかりません」                                               | 400 Bad Request、フィルタエリアにエラー表示     |
| 無効なページ番号   | 「ページ番号が範囲外です」                                                       | 400 Bad Request、1ページ目を表示                |
| データ取得失敗     | 「データの取得に失敗しました」                                                   | 500 Internal Server Error、エラーメッセージ表示 |
| CSV出力件数超過    | 「出力可能な最大件数(10,000件)を超えています。フィルタ条件を絞り込んでください」 | 400 Bad Request、警告ダイアログ表示             |
| CSV出力失敗        | 「CSVファイルの生成に失敗しました」                                              | 500 Internal Server Error、エラーメッセージ表示 |
| ネットワークエラー | 「サーバーとの通信に失敗しました」                                               | 接続エラー、再試行ボタン表示                    |

**エラー表示の原則:**

- フィルタエラー: フィルタエリア上部に赤背景で表示
- データ取得エラー: テーブルエリアに大きく表示、再読み込みボタン提供
- CSV出力エラー: モーダルダイアログで表示
- 軽微なエラー: トースト通知で表示（3秒後に自動消去）

## UX向上の工夫

### 1. 初期表示の最適化

- 初回アクセス時: 当月の全伝票を表示（最も一般的なユースケース）
- フィルタ状態をlocalStorageに保存（前回の検索条件を復元）

### 2. レスポンシブ対応

- モバイル表示時: 重要項目のみ表示（種別、伝票番号、日付、ステータス）
- 詳細項目: タップで展開表示

### 3. パフォーマンス

- 仮想スクロール対応（100件以上表示時）
- キャッシュ機能（同一条件での再検索はキャッシュから取得）
- 遅延ロード（スクロールに応じて追加読み込み）

### 4. アクセシビリティ

- キーボード操作: Tab/Enterでフィルタ・ページング操作可能
- スクリーンリーダー対応: ARIAラベル設定
- 色覚サポート: アイコンと色の併用で種別・ステータスを表現

### 5. データの可視化

- ステータス別集計: 画面上部に「下書き: 5件、確定: 10件、完了: 8件」のようなサマリー表示
- グラフ表示: 期間別の入出荷件数を折れ線グラフで可視化（オプション機能）
