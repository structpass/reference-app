# A-2 商品マスタ詳細入力

## 基本情報

| 項目       | 内容               |
| ---------- | ------------------ |
| 機能ID     | A-2                |
| 機能名     | 商品マスタ詳細入力 |
| 画面種別   | 登録/編集/閲覧     |
| ステータス | DONE               |
| 備考       |                    |

---

## 機能概要

商品マスタの新規登録・編集・閲覧を行う画面。3つのモード（登録・編集・閲覧）で動作し、ADMIN系ロール（WH_ADMIN、OF_ADMIN、SYS_ADMIN）は登録・編集が可能、USER系ロール（WH_USER、OF_USER）は閲覧モードのみアクセス可能。

## 画面レイアウト

- ヘッダー: タイトル（モードに応じて「商品登録」「商品編集」「商品詳細」）、戻るボタン
- フォームエリア: 入力項目（登録・編集モード）または表示項目（閲覧モード）
- フッター: 保存ボタン・削除ボタン（登録・編集モードのみ）、キャンセルボタン

## 画面モード

| モード | 説明               | 遷移条件                                                           |
| ------ | ------------------ | ------------------------------------------------------------------ |
| 登録   | 新規商品を登録する | A-1の「新規登録」ボタンから遷移（ADMIN系のみ）                     |
| 編集   | 既存商品を編集する | A-1の「編集」ボタンから遷移（ADMIN系のみ）、URLに商品ID含む        |
| 閲覧   | 既存商品を閲覧する | A-1の「詳細」ボタンから遷移（全ロール）、URLに商品ID含む、入力不可 |

## 入力項目

| #   | 項目名     | 型     | 必須 | 初期値 | バリデーション                   | 備考                               |
| --- | ---------- | ------ | ---- | ------ | -------------------------------- | ---------------------------------- |
| 1   | 商品コード | string | ○    | -      | 半角英数字、最大20文字、ユニーク | product_code                       |
| 2   | 商品名     | string | ○    | -      | 最大100文字                      | name                               |
| 3   | カテゴリ   | string | ○    | -      | 最大50文字                       | category（プルダウンまたは入力）   |
| 4   | 単位       | string | ○    | 個     | 最大10文字                       | unit（例: 個、箱、kg）             |
| 5   | 単価       | number | ○    | 0      | 0以上、整数                      | unit_price（円）                   |
| 6   | JANコード  | string | -    | -      | 13桁または8桁の数字              | jan_code                           |
| 7   | ステータス | string | ○    | active | active/inactive                  | status（ラジオボタンまたはトグル） |
| 8   | 備考       | string | -    | -      | 最大500文字                      | notes                              |

## 処理仕様

### 登録モード

1. 入力フォームを初期状態で表示
2. ユーザーが必須項目を入力
3. 「保存」ボタン押下で入力バリデーション実行
4. バリデーションOKの場合、POST API実行
5. 成功時: 成功メッセージ表示後、A-1へ遷移
6. 失敗時: エラーメッセージ表示（画面に留まる）

### 編集モード

1. URLパラメータの商品IDで GET API実行
2. 取得データをフォームに表示
3. ユーザーが項目を編集
4. 「保存」ボタン押下で入力バリデーション実行
5. バリデーションOKの場合、PUT API実行
6. 成功時: 成功メッセージ表示後、A-1へ遷移
7. 失敗時: エラーメッセージ表示（画面に留まる）

### 閲覧モード

1. URLパラメータの商品IDで GET API実行
2. 取得データを表示（入力不可）
3. 「戻る」ボタン押下でA-1へ遷移

### 削除処理（編集モードのみ）

1. 「削除」ボタン押下で確認ダイアログ表示
2. 確認OKの場合、DELETE API実行
3. 成功時: 成功メッセージ表示後、A-1へ遷移
4. 失敗時: エラーメッセージ表示（画面に留まる）

## API

| メソッド | エンドポイント       | 説明                              |
| -------- | -------------------- | --------------------------------- |
| GET      | /api/v1/products/:id | 商品1件取得（編集・閲覧モード用） |
| POST     | /api/v1/products     | 商品新規登録                      |
| PUT      | /api/v1/products/:id | 商品更新                          |
| DELETE   | /api/v1/products/:id | 商品削除                          |

### リクエスト例（POST/PUT）

```json
{
  "product_code": "P001",
  "name": "商品A",
  "category": "食品",
  "unit": "個",
  "unit_price": 100,
  "jan_code": "4901234567890",
  "status": "active",
  "notes": "備考"
}
```

### レスポンス例（GET）

```json
{
  "success": true,
  "data": {
    "id": "uuid",
    "product_code": "P001",
    "name": "商品A",
    "category": "食品",
    "unit": "個",
    "unit_price": 100,
    "jan_code": "4901234567890",
    "status": "active",
    "notes": "備考",
    "created_at": "2026-03-01T00:00:00Z",
    "updated_at": "2026-03-01T00:00:00Z"
  }
}
```

## 権限

| ロール    | 許可される操作         |
| --------- | ---------------------- |
| WH_USER   | 閲覧のみ               |
| WH_ADMIN  | 登録、編集、削除、閲覧 |
| OF_USER   | 閲覧のみ               |
| OF_ADMIN  | 登録、編集、削除、閲覧 |
| SYS_ADMIN | 登録、編集、削除、閲覧 |

## エラーハンドリング

| エラー条件          | メッセージ                                           | 挙動                          |
| ------------------- | ---------------------------------------------------- | ----------------------------- |
| 必須項目未入力      | 「{項目名}は必須です」                               | フォーム下部に赤字表示        |
| 商品コード重複      | 「この商品コードは既に使用されています」             | フォーム下部に赤字表示（409） |
| 文字数超過          | 「{項目名}は{最大文字数}文字以内で入力してください」 | フォーム下部に赤字表示        |
| 数値範囲外          | 「単価は0以上の整数を入力してください」              | フォーム下部に赤字表示        |
| JANコード形式エラー | 「JANコードは8桁または13桁の数字を入力してください」 | フォーム下部に赤字表示        |
| 商品が存在しない    | 「商品が見つかりません」                             | エラーページ表示（404）       |
| 権限不足            | 「この操作を実行する権限がありません」               | エラーページ表示（403）       |
| ネットワークエラー  | 「通信エラーが発生しました。再度お試しください」     | トースト通知表示              |
