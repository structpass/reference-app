# A-6 倉庫マスタ検索

## 基本情報

| 項目       | 内容           |
| ---------- | -------------- |
| 機能ID     | A-6            |
| 機能名     | 倉庫マスタ検索 |
| 画面種別   | 検索条件       |
| ステータス | DONE           |
| 備考       |                |

---

## 機能概要

倉庫マスタを複数の条件で検索する機能。検索条件を入力して「検索」ボタンを押すと、条件に合致する倉庫一覧をA-4画面で表示する。全ロールがアクセス可能。

## 画面レイアウト

- ヘッダー: タイトル「倉庫検索」、戻るボタン
- 検索条件エリア: 入力フォーム（複数条件）
- フッター: 検索ボタン、条件クリアボタン、キャンセルボタン

## 検索条件

| #   | 項目名               | 型     | 検索方式 | 初期値 | 備考                                     |
| --- | -------------------- | ------ | -------- | ------ | ---------------------------------------- |
| 1   | 倉庫コード           | string | 部分一致 | -      | warehouse_code（前方一致または完全一致） |
| 2   | 倉庫名               | string | 部分一致 | -      | name（あいまい検索）                     |
| 3   | 住所                 | string | 部分一致 | -      | address（あいまい検索）                  |
| 4   | 担当者               | string | 部分一致 | -      | manager（あいまい検索）                  |
| 5   | キャパシティ（範囲） | number | 範囲指定 | -      | capacity_min、capacity_max               |
| 6   | ステータス           | string | 完全一致 | -      | status（有効/無効/全て、ラジオボタン）   |

## 処理仕様

### 検索実行フロー

1. ユーザーが検索条件を入力
2. 「検索」ボタン押下
3. 入力された条件をクエリパラメータとしてGET API実行
4. 検索結果をA-4画面で表示（検索条件を保持）
5. 結果が0件の場合、「該当データがありません」メッセージを表示

### 条件クリアフロー

1. 「条件クリア」ボタン押下
2. 全入力項目を初期状態にリセット

### キャンセルフロー

1. 「キャンセル」ボタン押下
2. A-4画面へ遷移（検索条件なし）

### 検索条件の保持

- 検索実行後、URLパラメータに条件を含める
- ブラウザバック時も条件を保持
- A-4画面で「検索条件をクリア」ボタンを表示（検索後のみ）

## API

| メソッド | エンドポイント     | 説明                                             |
| -------- | ------------------ | ------------------------------------------------ |
| GET      | /api/v1/warehouses | 倉庫一覧取得（検索条件をクエリパラメータで指定） |

### リクエスト例

```
GET /api/v1/warehouses?page=1&limit=20&warehouse_code=W00&name=東京&address=千代田区&manager=山田&capacity_min=500&capacity_max=2000&status=active
```

### クエリパラメータ

| パラメータ     | 型     | 説明                                           |
| -------------- | ------ | ---------------------------------------------- |
| warehouse_code | string | 倉庫コード（部分一致）                         |
| name           | string | 倉庫名（部分一致）                             |
| address        | string | 住所（部分一致）                               |
| manager        | string | 担当者（部分一致）                             |
| capacity_min   | number | キャパシティ最小値                             |
| capacity_max   | number | キャパシティ最大値                             |
| status         | string | ステータス（active/inactive）                  |
| page           | number | ページ番号（デフォルト: 1）                    |
| limit          | number | 表示件数（デフォルト: 20）                     |
| sort           | string | ソートフィールド（デフォルト: warehouse_code） |
| order          | string | ソート順（asc/desc、デフォルト: asc）          |
