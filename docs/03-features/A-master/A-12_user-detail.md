# A-12 ユーザーマスタ詳細入力

## 基本情報

| 項目       | 内容                   |
| ---------- | ---------------------- |
| 機能ID     | A-12                   |
| 機能名     | ユーザーマスタ詳細入力 |
| 画面種別   | 登録/編集/閲覧         |
| ステータス | DONE                   |
| 備考       |                        |

---

## 機能概要

ユーザー情報の新規登録・編集・閲覧を行う画面。3つのモード（登録/編集/閲覧）を持ち、ロールに応じてアクセス可能なモードが制限される。パスワードはハッシュ化して保存し、編集時は空欄の場合は変更なしとして扱う。

## 画面レイアウト

### ヘッダー部

- タイトル:
  - 登録モード: 「ユーザー新規登録」
  - 編集モード: 「ユーザー編集」
  - 閲覧モード: 「ユーザー詳細」
- パンくずリスト: ホーム > ユーザーマスタ一覧 > [現在の画面]

### フォーム部

- 入力フィールド（下記「入力項目」参照）
- 所属グループ: 複数選択可能なセレクトボックス
- バリデーションエラー表示: 各フィールド下に赤文字で表示

### フッター部

- 登録モード: [登録] [キャンセル]
- 編集モード: [保存] [キャンセル]
- 閲覧モード: [編集] [一覧に戻る]（ADMIN系のみ[編集]表示）

## 画面モード

| モード | 説明                           | 遷移条件                                                                   |
| ------ | ------------------------------ | -------------------------------------------------------------------------- |
| 登録   | 新規ユーザーを作成             | A-11一覧画面の[新規登録]ボタンクリック                                     |
| 編集   | 既存ユーザー情報を更新         | A-11一覧画面の[編集]ボタンクリック、または閲覧モードの[編集]ボタンクリック |
| 閲覧   | ユーザー情報を表示（入力不可） | A-11一覧画面の行クリックまたは[詳細]ボタンクリック                         |

## 入力項目

| #   | 項目名             | 型           | 必須 | 初期値  | バリデーション                                                 | 備考                                             |
| --- | ------------------ | ------------ | ---- | ------- | -------------------------------------------------------------- | ------------------------------------------------ |
| 1   | ユーザーID         | string       | ○    | -       | 半角英数字・ハイフン・アンダースコア、4-50文字、一意性チェック | user_id、登録後は変更不可                        |
| 2   | ユーザー名         | string       | ○    | -       | 1-100文字                                                      | name                                             |
| 3   | メールアドレス     | string       | ○    | -       | メール形式チェック、一意性チェック                             | email                                            |
| 4   | パスワード         | string       | ○※   | -       | 半角英数字記号、8-100文字、英大小数字を各1文字以上含む         | password、※登録時のみ必須、編集時は空欄=変更なし |
| 5   | パスワード（確認） | string       | ○※   | -       | パスワードと一致                                               | password_confirmation、※登録時のみ必須           |
| 6   | ロール             | select       | ○    | WH_USER | WH_USER/WH_ADMIN/OF_USER/OF_ADMIN/SYS_ADMIN                    | role、プルダウン選択                             |
| 7   | 所属グループ       | multi-select | -    | []      | 存在するグループIDのみ                                         | groups、複数選択可能                             |
| 8   | ステータス         | select       | ○    | active  | active/inactive                                                | status、ラジオボタンまたはトグル                 |

### ロール選択肢

- `WH_USER`: 倉庫担当・一般
- `WH_ADMIN`: 倉庫担当・管理者
- `OF_USER`: 事務担当・一般
- `OF_ADMIN`: 事務担当・管理者
- `SYS_ADMIN`: システム管理者

### ステータス選択肢

- `active`: 有効
- `inactive`: 無効

## 処理仕様

### 登録モード

#### 初期表示

1. 全フィールドを空欄で表示
2. ロールのデフォルト値: WH_USER
3. ステータスのデフォルト値: active
4. 所属グループ選択肢: APIから取得したグループ一覧を表示

#### バリデーション（リアルタイム）

1. ユーザーID: 入力時に形式チェック、フォーカスアウト時に一意性チェック
2. メールアドレス: 入力時に形式チェック、フォーカスアウト時に一意性チェック
3. パスワード: 入力時に強度チェック（8文字以上、英大小数字各1文字以上）
4. パスワード（確認）: 入力時にパスワードとの一致チェック

#### 登録処理

1. [登録]ボタンクリック時に全フィールドのバリデーション実行
2. エラーがある場合は最初のエラーフィールドにフォーカス
3. バリデーション成功時、POST APIを実行
4. 成功時: 成功トースト表示、A-11一覧画面に遷移
5. 失敗時: エラートースト表示、画面維持

### 編集モード

#### 初期表示

1. APIから指定IDのユーザー情報を取得
2. 取得したデータを各フィールドに設定
3. ユーザーIDフィールドは読み取り専用（disabled）
4. パスワードフィールドは空欄で表示（placeholderに「変更しない場合は空欄」と表示）

#### 更新処理

1. [保存]ボタンクリック時に変更されたフィールドのみバリデーション実行
2. パスワードフィールドが空欄の場合はパスワード更新をスキップ
3. パスワードフィールドに入力がある場合は強度チェック＋確認フィールドとの一致チェック
4. バリデーション成功時、PUT APIを実行
5. 成功時: 成功トースト表示、A-11一覧画面に遷移
6. 失敗時: エラートースト表示、画面維持

### 閲覧モード

#### 初期表示

1. APIから指定IDのユーザー情報を取得
2. 全フィールドを読み取り専用で表示
3. パスワードフィールドは非表示（またはマスク「**\*\*\*\***」）
4. ADMIN系ロールの場合は[編集]ボタン表示

#### 編集モード遷移

1. [編集]ボタンクリック時に編集モードに切替
2. URLを `/users/:id/edit` に変更

## API

| メソッド | エンドポイント    | 説明                                       |
| -------- | ----------------- | ------------------------------------------ |
| GET      | /api/v1/users/:id | 指定ユーザー情報を取得                     |
| POST     | /api/v1/users     | 新規ユーザーを登録                         |
| PUT      | /api/v1/users/:id | 既存ユーザー情報を更新                     |
| DELETE   | /api/v1/users/:id | 指定ユーザーを削除（一覧画面から実行）     |
| GET      | /api/v1/groups    | グループ一覧を取得（所属グループ選択肢用） |

### リクエスト例（POST /api/v1/users）

```json
{
  "user_id": "tanaka_taro",
  "name": "田中太郎",
  "email": "tanaka@example.com",
  "password": "SecurePass123!",
  "role": "WH_USER",
  "groups": ["grp001", "grp002"],
  "status": "active"
}
```

### リクエスト例（PUT /api/v1/users/:id）

```json
{
  "name": "田中太郎（更新）",
  "email": "tanaka_new@example.com",
  "password": "",
  "role": "WH_ADMIN",
  "groups": ["grp001"],
  "status": "active"
}
```

### レスポンス例（GET /api/v1/users/:id）

```json
{
  "success": true,
  "data": {
    "id": "user001",
    "user_id": "tanaka_taro",
    "name": "田中太郎",
    "email": "tanaka@example.com",
    "role": "WH_USER",
    "groups": [
      { "id": "grp001", "name": "倉庫Aグループ" },
      { "id": "grp002", "name": "倉庫Bグループ" }
    ],
    "status": "active",
    "last_login_at": "2026-03-15T14:20:00Z",
    "created_at": "2025-01-10T09:00:00Z",
    "updated_at": "2026-03-16T10:30:00Z"
  }
}
```

## 権限

| ロール    | 許可される操作                      |
| --------- | ----------------------------------- |
| SYS_ADMIN | CRUD（全モードアクセス可能）        |
| WH_ADMIN  | CRUD（全モードアクセス可能）        |
| OF_ADMIN  | CRUD（全モードアクセス可能）        |
| WH_USER   | R（閲覧モードのみ、登録・編集不可） |
| OF_USER   | R（閲覧モードのみ、登録・編集不可） |

## エラーハンドリング

| エラー条件                | メッセージ                                                                       | 挙動                                         |
| ------------------------- | -------------------------------------------------------------------------------- | -------------------------------------------- |
| 必須フィールド未入力      | 「{フィールド名}は必須です」                                                     | 該当フィールド下にエラー表示、フォーカス移動 |
| ユーザーID形式不正        | 「ユーザーIDは半角英数字・ハイフン・アンダースコアで4-50文字で入力してください」 | 該当フィールド下にエラー表示                 |
| ユーザーID重複（409）     | 「このユーザーIDは既に使用されています」                                         | 該当フィールド下にエラー表示                 |
| メールアドレス形式不正    | 「正しいメールアドレス形式で入力してください」                                   | 該当フィールド下にエラー表示                 |
| メールアドレス重複（409） | 「このメールアドレスは既に使用されています」                                     | 該当フィールド下にエラー表示                 |
| パスワード強度不足（400） | 「パスワードは8文字以上で、英大文字・英小文字・数字を各1文字以上含めてください」 | 該当フィールド下にエラー表示                 |
| パスワード不一致          | 「パスワードが一致しません」                                                     | パスワード（確認）フィールド下にエラー表示   |
| ユーザー不存在（404）     | 「指定されたユーザーが見つかりません」                                           | エラートースト表示、一覧に戻る               |
| 権限不足（403）           | 「この操作を実行する権限がありません」                                           | エラートースト表示、一覧に戻る               |
| サーバーエラー（500）     | 「ユーザー情報の保存に失敗しました。時間をおいて再度お試しください」             | エラートースト表示、画面維持                 |
| ネットワークエラー        | 「通信エラーが発生しました。ネットワーク接続を確認してください」                 | エラートースト表示、画面維持                 |
