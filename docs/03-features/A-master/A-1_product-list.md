# A-1 商品マスタ一覧

## 基本情報

| 項目       | 内容           |
| ---------- | -------------- |
| 機能ID     | A-1            |
| 機能名     | 商品マスタ一覧 |
| 画面種別   | 一覧           |
| ステータス | DONE           |
| 備考       |                |

---

## 機能概要

商品マスタの一覧表示機能。登録されている商品情報を一覧形式で表示し、新規登録・編集・削除・検索・CSV出力などの操作を行う。全ロールがアクセス可能だが、新規登録・編集・削除はADMIN系ロール（WH_ADMIN、OF_ADMIN、SYS_ADMIN）のみ実行可能。

## 画面レイアウト

- ヘッダー: タイトル「商品マスタ一覧」
- 操作エリア: 新規登録ボタン（ADMIN系のみ）、検索ボタン、CSV出力ボタン
- 一覧テーブル: ソート可能なカラムヘッダー、データ行、操作ボタン（詳細・編集・削除）
- フッター: ページネーション（件数選択、前へ・次へ、ページ番号）

## 一覧表示項目

| #   | 項目名     | 型     | ソート | 備考                                                        |
| --- | ---------- | ------ | ------ | ----------------------------------------------------------- |
| 1   | 商品コード | string | 可     | product_code（ユニーク）                                    |
| 2   | 商品名     | string | 可     | name                                                        |
| 3   | カテゴリ   | string | 可     | category（Category テーブルの name。DB上は category_id FK） |
| 4   | 単位       | string | -      | unit（例: 個、箱、kg）                                      |
| 5   | 単価       | number | 可     | unit_price（円表示）                                        |
| 6   | JANコード  | string | -      | jan_code                                                    |
| 7   | ステータス | string | 可     | status（有効/無効）、バッジ表示                             |
| 8   | 操作       | -      | -      | 詳細・編集・削除ボタン                                      |

## ページネーション

| 項目               | 値           |
| ------------------ | ------------ |
| デフォルト表示件数 | 20件         |
| 選択可能件数       | 10/20/50/100 |

## 操作ボタン

| ボタン名 | 動作                                     | 権限                          | 備考                   |
| -------- | ---------------------------------------- | ----------------------------- | ---------------------- |
| 新規登録 | A-2（登録モード）へ遷移                  | WH_ADMIN, OF_ADMIN, SYS_ADMIN | ヘッダー右上に配置     |
| 検索     | A-3（検索画面）へ遷移                    | 全ロール                      | ヘッダー右上に配置     |
| CSV出力  | 現在の一覧データをCSV形式でダウンロード  | 全ロール                      | ヘッダー右上に配置     |
| 詳細     | A-2（閲覧モード）へ遷移                  | 全ロール                      | 各行の操作カラムに配置 |
| 編集     | A-2（編集モード）へ遷移                  | WH_ADMIN, OF_ADMIN, SYS_ADMIN | 各行の操作カラムに配置 |
| 削除     | 削除確認ダイアログ表示後、DELETE API実行 | WH_ADMIN, OF_ADMIN, SYS_ADMIN | 各行の操作カラムに配置 |

## API

| メソッド | エンドポイント       | 説明                                         |
| -------- | -------------------- | -------------------------------------------- |
| GET      | /api/v1/products     | 商品一覧取得（ページネーション、ソート対応） |
| DELETE   | /api/v1/products/:id | 商品削除                                     |

### リクエスト例（GET）

```
GET /api/v1/products?page=1&limit=20&sort=product_code&order=asc
```

## 権限

| ロール    | 許可される操作                                                    |
| --------- | ----------------------------------------------------------------- |
| WH_USER   | 一覧表示、詳細閲覧、CSV出力、検索                                 |
| WH_ADMIN  | 全操作（一覧表示、詳細閲覧、新規登録、編集、削除、CSV出力、検索） |
| OF_USER   | 一覧表示、詳細閲覧、CSV出力、検索                                 |
| OF_ADMIN  | 全操作（一覧表示、詳細閲覧、新規登録、編集、削除、CSV出力、検索） |
| SYS_ADMIN | 全操作（一覧表示、詳細閲覧、新規登録、編集、削除、CSV出力、検索） |
