## 機能概要

システムに登録されている全ユーザーを一覧表示する画面。ページネーション、ソート、行クリックによる詳細画面遷移をサポート。ロールに応じて新規登録・編集・削除ボタンの表示制御を行う。

## 画面レイアウト

### ヘッダー部

- タイトル: 「ユーザーマスタ一覧」
- [新規登録] ボタン: 右上（ADMIN系ロールのみ表示）
- [検索] ボタン: A-13 ユーザー・グループ検索へのリンク

### テーブル部

- 一覧テーブル（レスポンシブ対応）
- 各列ヘッダーにソートアイコン
- 行ホバー時に背景色変更
- 行クリックで詳細画面へ遷移

### フッター部

- ページネーションコントロール（前へ/次へ、ページ番号）
- 表示件数セレクト（10/20/50/100件）
- 全件数表示（例: 「全 247 件中 1-20 件を表示」）

## 一覧表示項目

| #   | 項目名           | 型       | ソート | 備考                                                         |
| --- | ---------------- | -------- | ------ | ------------------------------------------------------------ |
| 1   | ユーザーID       | string   | ○      | user_id、主キー                                              |
| 2   | ユーザー名       | string   | ○      | name                                                         |
| 3   | メールアドレス   | string   | ○      | email                                                        |
| 4   | ロール           | string   | ○      | role、日本語表示（WH_USER→倉庫担当・一般）                   |
| 5   | 所属グループ     | string   | ×      | 複数所属時はカンマ区切り、最大3つまで表示（「他2件」と表示） |
| 6   | ステータス       | string   | ○      | status、バッジ表示（active: 緑、inactive: グレー）           |
| 7   | 最終ログイン日時 | datetime | ○      | last_login_at、YYYY-MM-DD HH:mm形式、未ログインは「-」       |
| 8   | 操作             | -        | ×      | [詳細]ボタン、ADMIN系のみ[編集][削除]ボタン表示              |

### ロール表示変換

- `WH_USER` → 倉庫担当・一般
- `WH_ADMIN` → 倉庫担当・管理者
- `OF_USER` → 事務担当・一般
- `OF_ADMIN` → 事務担当・管理者
- `SYS_ADMIN` → システム管理者

### ステータス表示

- `active`: 緑色バッジ「有効」
- `inactive`: グレー色バッジ「無効」

## 処理仕様

### 初期表示

1. デフォルトソート: 最終ログイン日時の降順
2. デフォルトページ: 1ページ目
3. デフォルト表示件数: 20件
4. APIから一覧データを取得して表示

### ソート処理

1. 列ヘッダークリック時にソート状態を切替（昇順↔降順）
2. 現在のソート列にアイコン表示（↑: 昇順、↓: 降順）
3. APIにソートパラメータを送信して再取得

### ページネーション処理

1. ページ変更時にAPIから該当ページのデータを取得
2. 表示件数変更時は1ページ目にリセット
3. URLクエリパラメータにページ番号と表示件数を保持（ブラウザバック対応）

### 削除処理

1. [削除]ボタンクリック時に確認ダイアログ表示
2. ダイアログ内容: 「ユーザー "{ユーザー名}" を削除しますか？この操作は取り消せません。」
3. [削除]確認後、DELETE API実行
4. 成功時: 成功トースト表示、一覧を再取得
5. 失敗時: エラートースト表示

## API

| メソッド | エンドポイント                                              | 説明                                               |
| -------- | ----------------------------------------------------------- | -------------------------------------------------- |
| GET      | /api/v1/users?page=1&limit=20&sort=last_login_at&order=desc | ユーザー一覧を取得（ページネーション、ソート対応） |
| DELETE   | /api/v1/users/:id                                           | 指定ユーザーを削除                                 |

### クエリパラメータ

- `page`: ページ番号（デフォルト: 1）
- `limit`: 表示件数（デフォルト: 20、選択可能: 10/20/50/100）
- `sort`: ソート対象列（user_id/name/email/role/status/last_login_at）
- `order`: ソート順（asc/desc、デフォルト: desc）

## 権限

| ロール    | 許可される操作                             |
| --------- | ------------------------------------------ |
| SYS_ADMIN | CRUD（全ユーザーの表示・登録・編集・削除） |
| WH_ADMIN  | CRUD（全ユーザーの表示・登録・編集・削除） |
| OF_ADMIN  | CRUD（全ユーザーの表示・登録・編集・削除） |
| WH_USER   | R（全ユーザーの閲覧のみ）                  |
| OF_USER   | R（全ユーザーの閲覧のみ）                  |

## エラーハンドリング

| エラー条件            | メッセージ                                                           | 挙動                                     |
| --------------------- | -------------------------------------------------------------------- | ---------------------------------------- |
| 権限不足（403）       | 「この操作を実行する権限がありません」                               | エラートースト表示、操作ボタン非表示     |
| ユーザー不存在（404） | 「指定されたユーザーが見つかりません」                               | エラートースト表示、一覧を再取得         |
| 削除失敗（409）       | 「このユーザーは削除できません（関連データが存在します）」           | エラートースト表示、画面維持             |
| サーバーエラー（500） | 「ユーザー一覧の取得に失敗しました。時間をおいて再度お試しください」 | エラートースト表示、再読み込みボタン表示 |
| ネットワークエラー    | 「通信エラーが発生しました。ネットワーク接続を確認してください」     | エラートースト表示、再読み込みボタン表示 |
