## 機能概要

ユーザーとグループを横断的に検索できる統合検索画面。検索条件を指定して、ユーザーとグループの両方を同時に検索し、結果をタブで切り替えて表示する。権限設定やマスタ管理において、関連するユーザー・グループを素早く見つけるために使用する。

## 画面レイアウト

### ヘッダー部

- タイトル: 「ユーザー・グループ検索」
- パンくずリスト: ホーム > ユーザー・グループ検索

### 検索条件部

- 検索対象: ラジオボタン [ユーザー] [グループ] [両方]（デフォルト: 両方）
- キーワード: テキスト入力（ユーザー名/ユーザーID/グループ名/グループコードを部分一致検索）
- ロール: プルダウン選択（全て/WH_USER/WH_ADMIN/OF_USER/OF_ADMIN/SYS_ADMIN）
- ステータス: プルダウン選択（全て/有効/無効）
- [検索] ボタン: 検索実行
- [クリア] ボタン: 検索条件をリセット

### 検索結果部

- タブ切替: [ユーザー（n件）] [グループ（n件）]
- 各タブ内に一覧テーブル表示
- ページネーション（デフォルト20件）

### ユーザータブ

- 表示項目: ユーザーID、ユーザー名、メールアドレス、ロール、ステータス、操作
- 操作: [詳細]ボタン → A-12ユーザーマスタ詳細入力（閲覧モード）へ遷移

### グループタブ

- 表示項目: グループコード、グループ名、説明、所属ユーザー数、ステータス、操作
- 操作: [詳細]ボタン → A-15グループマスタ詳細入力（閲覧モード）へ遷移

## 検索条件

| #   | 項目名     | 型     | 検索方式 | 初期値 | 備考                                                                |
| --- | ---------- | ------ | -------- | ------ | ------------------------------------------------------------------- |
| 1   | 検索対象   | radio  | -        | 両方   | user/group/both                                                     |
| 2   | キーワード | string | 部分一致 | 空欄   | ユーザー名/ユーザーID/グループ名/グループコード対象                 |
| 3   | ロール     | select | 完全一致 | 全て   | WH_USER/WH_ADMIN/OF_USER/OF_ADMIN/SYS_ADMIN、ユーザー検索時のみ有効 |
| 4   | ステータス | select | 完全一致 | 全て   | active/inactive                                                     |

## 検索結果表示

### タブ切替動作

1. 初期表示時は「ユーザー」タブを選択状態で表示
2. タブクリックで表示切替（APIの再実行なし、既に取得済みのデータを表示）
3. タブ名に検索結果件数を表示（例: 「ユーザー（12件）」「グループ（5件）」）

### ユーザー検索結果

| #   | 項目名         | 型     | ソート | 備考                                 |
| --- | -------------- | ------ | ------ | ------------------------------------ |
| 1   | ユーザーID     | string | ○      | user_id                              |
| 2   | ユーザー名     | string | ○      | name、キーワード一致箇所をハイライト |
| 3   | メールアドレス | string | ○      | email                                |
| 4   | ロール         | string | ○      | role、日本語表示                     |
| 5   | ステータス     | string | ○      | status、バッジ表示                   |
| 6   | 操作           | -      | ×      | [詳細]ボタン                         |

### グループ検索結果

| #   | 項目名         | 型     | ソート | 備考                                       |
| --- | -------------- | ------ | ------ | ------------------------------------------ |
| 1   | グループコード | string | ○      | group_code、キーワード一致箇所をハイライト |
| 2   | グループ名     | string | ○      | name、キーワード一致箇所をハイライト       |
| 3   | 説明           | string | ×      | description、50文字で省略                  |
| 4   | 所属ユーザー数 | number | ○      | members.length                             |
| 5   | ステータス     | string | ○      | status、バッジ表示                         |
| 6   | 操作           | -      | ×      | [詳細]ボタン                               |

### ページネーション

- デフォルト表示件数: 20件
- 選択可能件数: 10/20/50/100件
- ユーザーとグループで独立したページネーション

## 処理仕様

### 初期表示

1. 検索条件を初期値で表示
2. 検索結果は空（検索実行前）
3. タブは非活性状態

### 検索実行

1. [検索]ボタンクリック時にバリデーション実行
2. 検索対象に応じてAPIを呼び分け
   - 「ユーザー」: GET /api/v1/users のみ実行
   - 「グループ」: GET /api/v1/groups のみ実行
   - 「両方」: GET /api/v1/users と GET /api/v1/groups を並列実行
3. 検索結果を取得後、タブを活性化
4. 結果件数をタブ名に表示
5. 結果0件の場合は「該当データが見つかりませんでした」メッセージ表示

### クリア処理

1. [クリア]ボタンクリック時に全検索条件を初期値にリセット
2. 検索結果をクリア
3. タブを非活性状態に戻す

### キーワードハイライト

1. 検索結果のユーザー名/ユーザーID/グループ名/グループコードにキーワードが含まれる場合、該当箇所を黄色背景でハイライト表示
2. 大文字小文字を区別せずに検索（case-insensitive）

## API

| メソッド | エンドポイント                                               | 説明         |
| -------- | ------------------------------------------------------------ | ------------ |
| GET      | /api/v1/users?search=xxx&role=xxx&status=xxx&page=1&limit=20 | ユーザー検索 |
| GET      | /api/v1/groups?search=xxx&status=xxx&page=1&limit=20         | グループ検索 |

### クエリパラメータ（ユーザー検索）

- `search`: キーワード（ユーザー名/ユーザーIDを部分一致検索）
- `role`: ロール（WH_USER/WH_ADMIN/OF_USER/OF_ADMIN/SYS_ADMIN）
- `status`: ステータス（active/inactive）
- `page`: ページ番号（デフォルト: 1）
- `limit`: 表示件数（デフォルト: 20）

### クエリパラメータ（グループ検索）

- `search`: キーワード（グループ名/グループコードを部分一致検索）
- `status`: ステータス（active/inactive）
- `page`: ページ番号（デフォルト: 1）
- `limit`: 表示件数（デフォルト: 20）

## 権限

| ロール    | 許可される操作                        |
| --------- | ------------------------------------- |
| SYS_ADMIN | R（全ユーザー・グループの検索・閲覧） |
| WH_ADMIN  | R（全ユーザー・グループの検索・閲覧） |
| OF_ADMIN  | R（全ユーザー・グループの検索・閲覧） |
| WH_USER   | R（全ユーザー・グループの検索・閲覧） |
| OF_USER   | R（全ユーザー・グループの検索・閲覧） |

## エラーハンドリング

| エラー条件            | メッセージ                                                       | 挙動                               |
| --------------------- | ---------------------------------------------------------------- | ---------------------------------- |
| 検索結果0件           | 「該当データが見つかりませんでした」                             | 検索結果エリアに情報メッセージ表示 |
| サーバーエラー（500） | 「検索に失敗しました。時間をおいて再度お試しください」           | エラートースト表示、検索条件維持   |
| ネットワークエラー    | 「通信エラーが発生しました。ネットワーク接続を確認してください」 | エラートースト表示、検索条件維持   |
| 権限不足（403）       | 「この操作を実行する権限がありません」                           | エラートースト表示、ホームに戻る   |
