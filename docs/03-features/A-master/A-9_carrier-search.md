# A-9 運送会社マスタ検索

## 基本情報

| 項目       | 内容               |
| ---------- | ------------------ |
| 機能ID     | A-9                |
| 機能名     | 運送会社マスタ検索 |
| 画面種別   | 検索条件           |
| ステータス | DONE               |
| 備考       |                    |

---

## 機能概要

運送会社マスタを複数の条件で検索する機能。検索条件を入力して「検索」ボタンを押すと、条件に合致する運送会社一覧をA-7画面で表示する。全ロールがアクセス可能。

## 画面レイアウト

- ヘッダー: タイトル「運送会社検索」、戻るボタン
- 検索条件エリア: 入力フォーム（複数条件）
- フッター: 検索ボタン、条件クリアボタン、キャンセルボタン

## 検索条件

| #   | 項目名         | 型     | 検索方式 | 初期値 | 備考                                   |
| --- | -------------- | ------ | -------- | ------ | -------------------------------------- |
| 1   | 運送会社コード | string | 部分一致 | -      | carrier_code（前方一致または完全一致） |
| 2   | 会社名         | string | 部分一致 | -      | name（あいまい検索）                   |
| 3   | 住所           | string | 部分一致 | -      | address（あいまい検索）                |
| 4   | 担当者         | string | 部分一致 | -      | contact_person（あいまい検索）         |
| 5   | メール         | string | 部分一致 | -      | email（部分一致）                      |
| 6   | ステータス     | string | 完全一致 | -      | status（有効/無効/全て、ラジオボタン） |

## 処理仕様

### 検索実行フロー

1. ユーザーが検索条件を入力
2. 「検索」ボタン押下
3. 入力された条件をクエリパラメータとしてGET API実行
4. 検索結果をA-7画面で表示（検索条件を保持）
5. 結果が0件の場合、「該当データがありません」メッセージを表示

### 条件クリアフロー

1. 「条件クリア」ボタン押下
2. 全入力項目を初期状態にリセット

### キャンセルフロー

1. 「キャンセル」ボタン押下
2. A-7画面へ遷移（検索条件なし）

### 検索条件の保持

- 検索実行後、URLパラメータに条件を含める
- ブラウザバック時も条件を保持
- A-7画面で「検索条件をクリア」ボタンを表示（検索後のみ）

## API

| メソッド | エンドポイント   | 説明                                                 |
| -------- | ---------------- | ---------------------------------------------------- |
| GET      | /api/v1/carriers | 運送会社一覧取得（検索条件をクエリパラメータで指定） |

### リクエスト例

```
GET /api/v1/carriers?page=1&limit=20&carrier_code=C00&name=ヤマト&address=東京&contact_person=佐藤&email=contact&status=active
```

### クエリパラメータ

| パラメータ     | 型     | 説明                                         |
| -------------- | ------ | -------------------------------------------- |
| carrier_code   | string | 運送会社コード（部分一致）                   |
| name           | string | 会社名（部分一致）                           |
| address        | string | 住所（部分一致）                             |
| contact_person | string | 担当者（部分一致）                           |
| email          | string | メール（部分一致）                           |
| status         | string | ステータス（active/inactive）                |
| page           | number | ページ番号（デフォルト: 1）                  |
| limit          | number | 表示件数（デフォルト: 20）                   |
| sort           | string | ソートフィールド（デフォルト: carrier_code） |
| order          | string | ソート順（asc/desc、デフォルト: asc）        |
