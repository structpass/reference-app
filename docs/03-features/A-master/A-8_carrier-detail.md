# A-8 運送会社マスタ詳細入力

## 基本情報

| 項目       | 内容                   |
| ---------- | ---------------------- |
| 機能ID     | A-8                    |
| 機能名     | 運送会社マスタ詳細入力 |
| 画面種別   | 登録/編集/閲覧         |
| ステータス | DONE                   |
| 備考       |                        |

---

## 機能概要

運送会社マスタの新規登録・編集・閲覧を行う画面。3つのモード（登録・編集・閲覧）で動作し、ADMIN系ロール（WH_ADMIN、OF_ADMIN、SYS_ADMIN）は登録・編集が可能、USER系ロール（WH_USER、OF_USER）は閲覧モードのみアクセス可能。

## 画面レイアウト

- ヘッダー: タイトル（モードに応じて「運送会社登録」「運送会社編集」「運送会社詳細」）、戻るボタン
- フォームエリア: 入力項目（登録・編集モード）または表示項目（閲覧モード）
- フッター: 保存ボタン・削除ボタン（登録・編集モードのみ）、キャンセルボタン

## 画面モード

| モード | 説明                   | 遷移条件                                                               |
| ------ | ---------------------- | ---------------------------------------------------------------------- |
| 登録   | 新規運送会社を登録する | A-7の「新規登録」ボタンから遷移（ADMIN系のみ）                         |
| 編集   | 既存運送会社を編集する | A-7の「編集」ボタンから遷移（ADMIN系のみ）、URLに運送会社ID含む        |
| 閲覧   | 既存運送会社を閲覧する | A-7の「詳細」ボタンから遷移（全ロール）、URLに運送会社ID含む、入力不可 |

## 入力項目

| #   | 項目名         | 型     | 必須 | 初期値 | バリデーション                   | 備考                               |
| --- | -------------- | ------ | ---- | ------ | -------------------------------- | ---------------------------------- |
| 1   | 運送会社コード | string | ○    | -      | 半角英数字、最大20文字、ユニーク | carrier_code                       |
| 2   | 会社名         | string | ○    | -      | 最大100文字                      | name                               |
| 3   | 住所           | string | ○    | -      | 最大200文字                      | address                            |
| 4   | 電話番号       | string | ○    | -      | 半角数字とハイフン、最大15文字   | phone（例: 03-9876-5432）          |
| 5   | 担当者         | string | ○    | -      | 最大50文字                       | contact_person                     |
| 6   | メール         | string | ○    | -      | メール形式、最大100文字          | email                              |
| 7   | ステータス     | string | ○    | active | active/inactive                  | status（ラジオボタンまたはトグル） |
| 8   | 備考           | string | -    | -      | 最大500文字                      | notes                              |

## 処理仕様

### 登録モード

1. 入力フォームを初期状態で表示
2. ユーザーが必須項目を入力
3. 「保存」ボタン押下で入力バリデーション実行
4. バリデーションOKの場合、POST API実行
5. 成功時: 成功メッセージ表示後、A-7へ遷移
6. 失敗時: エラーメッセージ表示（画面に留まる）

### 編集モード

1. URLパラメータの運送会社IDで GET API実行
2. 取得データをフォームに表示
3. ユーザーが項目を編集
4. 「保存」ボタン押下で入力バリデーション実行
5. バリデーションOKの場合、PUT API実行
6. 成功時: 成功メッセージ表示後、A-7へ遷移
7. 失敗時: エラーメッセージ表示（画面に留まる）

### 閲覧モード

1. URLパラメータの運送会社IDで GET API実行
2. 取得データを表示（入力不可）
3. 「戻る」ボタン押下でA-7へ遷移

### 削除処理（編集モードのみ）

1. 「削除」ボタン押下で確認ダイアログ表示
2. 確認OKの場合、DELETE API実行
3. 成功時: 成功メッセージ表示後、A-7へ遷移
4. 失敗時: エラーメッセージ表示（画面に留まる）

## API

| メソッド | エンドポイント       | 説明                                  |
| -------- | -------------------- | ------------------------------------- |
| GET      | /api/v1/carriers/:id | 運送会社1件取得（編集・閲覧モード用） |
| POST     | /api/v1/carriers     | 運送会社新規登録                      |
| PUT      | /api/v1/carriers/:id | 運送会社更新                          |
| DELETE   | /api/v1/carriers/:id | 運送会社削除                          |

### リクエスト例（POST/PUT）

```json
{
  "carrier_code": "C001",
  "name": "ヤマト運輸",
  "address": "東京都中央区2-2-2",
  "phone": "03-9876-5432",
  "contact_person": "佐藤花子",
  "email": "contact@carrier.example.com",
  "status": "active",
  "notes": "備考"
}
```

### レスポンス例（GET）

```json
{
  "success": true,
  "data": {
    "id": "uuid",
    "carrier_code": "C001",
    "name": "ヤマト運輸",
    "address": "東京都中央区2-2-2",
    "phone": "03-9876-5432",
    "contact_person": "佐藤花子",
    "email": "contact@carrier.example.com",
    "status": "active",
    "notes": "備考",
    "created_at": "2026-03-01T00:00:00Z",
    "updated_at": "2026-03-01T00:00:00Z"
  }
}
```

## 権限

| ロール    | 許可される操作         |
| --------- | ---------------------- |
| WH_USER   | 閲覧のみ               |
| WH_ADMIN  | 登録、編集、削除、閲覧 |
| OF_USER   | 閲覧のみ               |
| OF_ADMIN  | 登録、編集、削除、閲覧 |
| SYS_ADMIN | 登録、編集、削除、閲覧 |

## エラーハンドリング

| エラー条件           | メッセージ                                           | 挙動                          |
| -------------------- | ---------------------------------------------------- | ----------------------------- |
| 必須項目未入力       | 「{項目名}は必須です」                               | フォーム下部に赤字表示        |
| 運送会社コード重複   | 「この運送会社コードは既に使用されています」         | フォーム下部に赤字表示（409） |
| 文字数超過           | 「{項目名}は{最大文字数}文字以内で入力してください」 | フォーム下部に赤字表示        |
| メール形式エラー     | 「メールアドレスの形式が正しくありません」           | フォーム下部に赤字表示        |
| 電話番号形式エラー   | 「電話番号は半角数字とハイフンで入力してください」   | フォーム下部に赤字表示        |
| 運送会社が存在しない | 「運送会社が見つかりません」                         | エラーページ表示（404）       |
| 権限不足             | 「この操作を実行する権限がありません」               | エラーページ表示（403）       |
| ネットワークエラー   | 「通信エラーが発生しました。再度お試しください」     | トースト通知表示              |
