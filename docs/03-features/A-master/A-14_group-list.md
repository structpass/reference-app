## 機能概要

システムに登録されている全グループを一覧表示する画面。グループは複数のユーザーをまとめて管理する単位として機能し、権限設定やアクセス制御に使用される。ページネーション、ソート、行クリックによる詳細画面遷移をサポート。

## 画面レイアウト

### ヘッダー部

- タイトル: 「グループマスタ一覧」
- [新規登録] ボタン: 右上（ADMIN系ロールのみ表示）
- [検索] ボタン: A-13 ユーザー・グループ検索へのリンク

### テーブル部

- 一覧テーブル（レスポンシブ対応）
- 各列ヘッダーにソートアイコン
- 行ホバー時に背景色変更
- 行クリックで詳細画面へ遷移

### フッター部

- ページネーションコントロール（前へ/次へ、ページ番号）
- 表示件数セレクト（10/20/50/100件）
- 全件数表示（例: 「全 42 件中 1-20 件を表示」）

## 一覧表示項目

| #   | 項目名         | 型     | ソート | 備考                                                             |
| --- | -------------- | ------ | ------ | ---------------------------------------------------------------- |
| 1   | グループID     | string | ○      | id、内部ID（非表示または縮小表示）                               |
| 2   | グループコード | string | ○      | group_code、主キー                                               |
| 3   | グループ名     | string | ○      | name                                                             |
| 4   | 説明           | string | ×      | description、50文字で省略、ツールチップで全文表示                |
| 5   | 所属ユーザー数 | number | ○      | member_count、数値右寄せ、クリックで所属ユーザー一覧ポップアップ |
| 6   | ステータス     | string | ○      | status、バッジ表示（active: 緑、inactive: グレー）               |
| 7   | 操作           | -      | ×      | [詳細]ボタン、ADMIN系のみ[編集][削除]ボタン表示                  |

### ステータス表示

- `active`: 緑色バッジ「有効」
- `inactive`: グレー色バッジ「無効」

### 所属ユーザー数列の動作

1. 数値をクリックすると、所属ユーザー一覧をモーダルで表示
2. モーダル内容: ユーザーID、ユーザー名、ロール、ステータス
3. モーダル内の各ユーザー行をクリックするとA-12ユーザー詳細画面に遷移

## ページネーション

| 項目               | 値             |
| ------------------ | -------------- |
| デフォルト表示件数 | 20件           |
| 選択可能件数       | 10/20/50/100件 |

## 操作ボタン

| ボタン名 | 動作                                            | 権限        | 備考               |
| -------- | ----------------------------------------------- | ----------- | ------------------ |
| 新規登録 | A-15 グループマスタ詳細入力（登録モード）へ遷移 | ADMIN系のみ | ヘッダー右上に配置 |
| 検索     | A-13 ユーザー・グループ検索へ遷移               | 全ロール    | ヘッダー部に配置   |
| 詳細     | A-15 グループマスタ詳細入力（閲覧モード）へ遷移 | 全ロール    | 各行の操作列       |
| 編集     | A-15 グループマスタ詳細入力（編集モード）へ遷移 | ADMIN系のみ | 各行の操作列       |
| 削除     | 削除確認ダイアログ表示後、DELETE API実行        | ADMIN系のみ | 各行の操作列       |

## 処理仕様

### 初期表示

1. デフォルトソート: グループコードの昇順
2. デフォルトページ: 1ページ目
3. デフォルト表示件数: 20件
4. APIから一覧データを取得して表示

### ソート処理

1. 列ヘッダークリック時にソート状態を切替（昇順↔降順）
2. 現在のソート列にアイコン表示（↑: 昇順、↓: 降順）
3. APIにソートパラメータを送信して再取得

### ページネーション処理

1. ページ変更時にAPIから該当ページのデータを取得
2. 表示件数変更時は1ページ目にリセット
3. URLクエリパラメータにページ番号と表示件数を保持（ブラウザバック対応）

### 削除処理

1. [削除]ボタンクリック時に確認ダイアログ表示
2. ダイアログ内容: 「グループ "{グループ名}" を削除しますか？所属ユーザーとの紐付けも解除されます。この操作は取り消せません。」
3. [削除]確認後、DELETE API実行
4. 成功時: 成功トースト表示、一覧を再取得
5. 失敗時: エラートースト表示

### 所属ユーザー一覧モーダル

1. 所属ユーザー数列の数値クリック時にモーダル表示
2. GET /api/v1/groups/:id/members を実行して所属ユーザー一覧を取得
3. モーダル内にユーザー一覧テーブル表示（ページネーションなし、最大100件）
4. 各ユーザー行クリックでA-12ユーザー詳細画面に遷移
5. [閉じる]ボタンまたはモーダル外クリックで閉じる

## API

| メソッド | エンドポイント                                           | 説明                                               |
| -------- | -------------------------------------------------------- | -------------------------------------------------- |
| GET      | /api/v1/groups?page=1&limit=20&sort=group_code&order=asc | グループ一覧を取得（ページネーション、ソート対応） |
| GET      | /api/v1/groups/:id/members                               | 指定グループの所属ユーザー一覧を取得               |
| DELETE   | /api/v1/groups/:id                                       | 指定グループを削除                                 |

### クエリパラメータ

- `page`: ページ番号（デフォルト: 1）
- `limit`: 表示件数（デフォルト: 20、選択可能: 10/20/50/100）
- `sort`: ソート対象列（group_code/name/member_count/status）
- `order`: ソート順（asc/desc、デフォルト: asc）

### レスポンス例（GET /api/v1/groups）

```json
{
  "success": true,
  "data": {
    "groups": [
      {
        "id": "grp001",

        "description": "倉庫A担当者のグループです。入出荷業務を担当します。",
        "member_count": 8,
        "status": "active",
        "created_at": "2025-01-01T00:00:00Z",
        "updated_at": "2026-03-10T14:20:00Z"

    ],
    "pagination": {
      "total": 42,
      "page": 1,
      "limit": 20,
      "total_pages": 3
    }
  }
}
```

## 権限

| ロール    | 許可される操作                             |
| --------- | ------------------------------------------ |
| SYS_ADMIN | CRUD（全グループの表示・登録・編集・削除） |
| WH_ADMIN  | CRUD（全グループの表示・登録・編集・削除） |
| OF_ADMIN  | CRUD（全グループの表示・登録・編集・削除） |
| WH_USER   | R（全グループの閲覧のみ）                  |
| OF_USER   | R（全グループの閲覧のみ）                  |

削除は、`role=SYS_ADMIN` のグループ（SYS_ADMIN のみ）と、依存データが残るグループ（所属ユーザーまたは掲示の宛先。`409`）では実行できません。詳細は A-15 の権限を参照。

## エラーハンドリング

| エラー条件            | メッセージ                                                                                                                                                                                                       | 挙動                                     |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| 権限不足（403）       | 「この操作を実行する権限がありません」                                                                                                                                                                           | エラートースト表示、操作ボタン非表示     |
| グループ不存在（404） | 「指定されたグループが見つかりません」                                                                                                                                                                           | エラートースト表示、一覧を再取得         |
| 削除失敗（409）       | API が返した理由（「このグループは掲示の宛先に指定されているため削除できません。宛先の変更はシステム管理者へご依頼ください」「このグループには所属ユーザーがいるため削除できません。先に所属を外してください」） | エラートースト表示、画面維持             |
| サーバーエラー（500） | 「グループ一覧の取得に失敗しました。時間をおいて再度お試しください」                                                                                                                                             | エラートースト表示、再読み込みボタン表示 |
| ネットワークエラー    | 「通信エラーが発生しました。ネットワーク接続を確認してください」                                                                                                                                                 | エラートースト表示、再読み込みボタン表示 |
