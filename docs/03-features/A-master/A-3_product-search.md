# A-3 商品マスタ検索

## 基本情報

| 項目       | 内容           |
| ---------- | -------------- |
| 機能ID     | A-3            |
| 機能名     | 商品マスタ検索 |
| 画面種別   | 検索条件       |
| ステータス | DONE           |
| 備考       |                |

---

## 機能概要

商品マスタを複数の条件で検索する機能。検索条件を入力して「検索」ボタンを押すと、条件に合致する商品一覧をA-1画面で表示する。全ロールがアクセス可能。

## 画面レイアウト

- ヘッダー: タイトル「商品検索」、戻るボタン
- 検索条件エリア: 入力フォーム（複数条件）
- フッター: 検索ボタン、条件クリアボタン、キャンセルボタン

## 検索条件

| #   | 項目名       | 型     | 検索方式 | 初期値 | 備考                                   |
| --- | ------------ | ------ | -------- | ------ | -------------------------------------- |
| 1   | 商品コード   | string | 部分一致 | -      | product_code（前方一致または完全一致） |
| 2   | 商品名       | string | 部分一致 | -      | name（あいまい検索）                   |
| 3   | カテゴリ     | string | 完全一致 | -      | category（プルダウン選択）             |
| 4   | 単価（範囲） | number | 範囲指定 | -      | unit_price_min、unit_price_max         |
| 5   | JANコード    | string | 完全一致 | -      | jan_code                               |
| 6   | ステータス   | string | 完全一致 | -      | status（有効/無効/全て、ラジオボタン） |

## 処理仕様

### 検索実行フロー

1. ユーザーが検索条件を入力
2. 「検索」ボタン押下
3. 入力された条件をクエリパラメータとしてGET API実行
4. 検索結果をA-1画面で表示（検索条件を保持）
5. 結果が0件の場合、「該当データがありません」メッセージを表示

### 条件クリアフロー

1. 「条件クリア」ボタン押下
2. 全入力項目を初期状態にリセット

### キャンセルフロー

1. 「キャンセル」ボタン押下
2. A-1画面へ遷移（検索条件なし）

### 検索条件の保持

- 検索実行後、URLパラメータに条件を含める
- ブラウザバック時も条件を保持
- A-1画面で「検索条件をクリア」ボタンを表示（検索後のみ）

## API

| メソッド | エンドポイント   | 説明                                             |
| -------- | ---------------- | ------------------------------------------------ |
| GET      | /api/v1/products | 商品一覧取得（検索条件をクエリパラメータで指定） |

### リクエスト例

```
GET /api/v1/products?page=1&limit=20&product_code=P00&name=商品&category=食品&unit_price_min=100&unit_price_max=500&jan_code=4901234567890&status=active
```

### クエリパラメータ

| パラメータ     | 型     | 説明                                         |
| -------------- | ------ | -------------------------------------------- |
| product_code   | string | 商品コード（部分一致）                       |
| name           | string | 商品名（部分一致）                           |
| category       | string | カテゴリ（完全一致）                         |
| unit_price_min | number | 単価最小値                                   |
| unit_price_max | number | 単価最大値                                   |
| jan_code       | string | JANコード（完全一致）                        |
| status         | string | ステータス（active/inactive）                |
| page           | number | ページ番号（デフォルト: 1）                  |
| limit          | number | 表示件数（デフォルト: 20）                   |
| sort           | string | ソートフィールド（デフォルト: product_code） |
| order          | string | ソート順（asc/desc、デフォルト: asc）        |
