# StructPass 利用者定義

## 利用組織

倉庫管理会社（荷主から委託を受けて倉庫運営を行う事業者）

---

## ロール体系

2つの業務区分 × 2つの権限レベル ＋ システム管理者 ＝ **5ロール**

### 業務区分

| 区分 | 担当業務       | 概要                                       |
| ---- | -------------- | ------------------------------------------ |
| 倉庫 | 入出庫チェック | 現場で入荷・出荷の検品・確認を行う         |
| 事務 | 余剰在庫管理   | 在庫状況を把握し、余剰在庫の削減を管理する |

### 権限レベル

| レベル | 説明                                                 |
| ------ | ---------------------------------------------------- |
| 一般   | 閲覧・日常業務の入力操作                             |
| 管理者 | 一般の権限に加え、マスタ編集・承認・削除等の管理操作 |

---

### 権限ルール要約

| ルール             | 対象          | 内容                                                                 |
| ------------------ | ------------- | -------------------------------------------------------------------- |
| マスタ管理CUD      | A-1〜A-15     | ADMIN系（WH_ADMIN, OF_ADMIN, SYS_ADMIN）のみ。USER系は閲覧(R)のみ    |
| 入出荷・発注の削除 | B-1, B-2, D-1 | ADMIN系のみ削除可。USER系はCRUまで                                   |
| 棚卸確定           | C-1           | ADMIN系のみ確定操作が可能。USER系は入力(CRU)まで                     |
| メニューフィルタ   | Z-2           | ロールの権限に応じて表示項目を動的にフィルタリング                   |
| A-10 権限設定      | A-10          | ロール単位で機能ごとの参照・登録・修正・削除の可否をカスタマイズ可能 |

A-10 権限設定の設定単位はロール（対象は SYS_ADMIN 以外の4ロール）で、行は 18 機能＋ユーザー定義台帳である。ユーザー単位・グループ単位の機能権限設定は未実装で、画面も無い。詳細は [A-10 機能別権限設定](../03-features/A-master/A-10_permission-settings.md) を参照する。

## ロール詳細

### WH_USER（倉庫担当・一般）

- **業務内容**: 入荷・出荷の現場オペレーション
- **主な作業**:
  - 入荷時の検品・数量確認
  - 出荷時のピッキング・検品確認
  - 入出荷伝票の入力
  - 棚卸作業の実施
- **利用頻度**: 毎日
- **利用デバイス**:

### WH_ADMIN（倉庫担当・管理者）

- **業務内容**: 倉庫業務の管理・監督
- **主な作業**:
  - WH_USER の全作業
  - 入出荷伝票の承認・修正・削除
  - 倉庫マスタの管理
  - 棚卸結果の確定
- **利用頻度**: 毎日
- **利用デバイス**:

### OF_USER（事務担当・一般）

- **業務内容**: 在庫状況の確認・日常事務
- **主な作業**:
  - 在庫状況の確認
  - 予測在庫の確認
  - 発注データの入力
  - 入出荷履歴の閲覧
- **利用頻度**: 毎日
- **利用デバイス**:

### OF_ADMIN（事務担当・管理者）

- **業務内容**: 余剰在庫の削減・在庫最適化の管理
- **主な作業**:
  - OF_USER の全作業
  - 発注の承認・修正・削除
  - 商品マスタ・運送会社マスタの管理
  - 在庫分析・レポート
- **利用頻度**: 毎日
- **利用デバイス**:

### SYS_ADMIN（システム管理者）

- **業務内容**: システム全体の運用・保守
- **主な作業**:
  - 全機能へのアクセス
  - ユーザーアカウントの管理
  - 全マスタデータの管理
  - システム設定
- **利用頻度**: 随時
- **利用デバイス**:
